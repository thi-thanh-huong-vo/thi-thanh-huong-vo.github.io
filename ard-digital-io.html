Ra khỏi LED trên bo: nối LED ngoài qua breadboard, tính điện trở hạn dòng, dùng biến, hằng số và vòng lặp for, đọc nút nhấn, và nhấp nháy mà không chặn chương trình bằng delay().

1. Breadboard và LED

Breadboard cho phép lắp mạch không cần hàn. Hai hàng dài ở mép (thường có vạch đỏ và xanh) là thanh nguồn và GND, nối thông theo chiều dài; ở giữa, mỗi cột 5 lỗ nối thông với nhau, và rãnh giữa ngăn hai nửa.

LED có cực: chân dài là anode (+), chân ngắn là cathode (−). Cắm ngược thì LED không sáng (nhưng không hỏng ở 5 V với điện trở nối tiếp).

2. Vì sao cần điện trở

LED là một diode: khi đã dẫn, điện áp trên nó gần như không đổi (VF khoảng 1,8–2,2 V với LED đỏ, khoảng 3 V với LED xanh dương, trắng), nên dòng chỉ bị giới hạn bởi điện trở nối tiếp:

$$R=\frac{V_{\text{nguồn}}-V_F}{I}$$

Chân của ATmega328P chịu tối đa tuyệt đối 40 mA và nên giữ dưới khoảng 20 mA. Với VF = 2 V và I = 15 mA, R = 200 Ω; giá trị chuẩn 220 Ω cho khoảng 14 mA.

3. Hằng số, biến và vòng lặp

LedPin9.inoChạy thử trên Wokwi ↗
// LedPin9.ino -- blink an external LED on pin 9
// Circuit: pin 9 -> 220 ohm resistor -> LED anode (long leg); LED cathode -> GND
const int LED = 9;                 // const: the pin number never changes

void setup() {
  pinMode(LED, OUTPUT);            // pins are inputs by default
}

void loop() {
  digitalWrite(LED, HIGH);         // 5 V
  delay(500);
  digitalWrite(LED, LOW);          // 0 V
  delay(500);
}

Nguồn: Viết cho trang này dựa trên bài giảng, dùng tự do

const int LED = 9; khai báo một số nguyên chỉ đọc. Đặt tên cho số chân giúp code dễ đọc và chỉ cần sửa một chỗ khi đổi chân. Kiểu int chứa số nguyên; các kiểu khác hay gặp là long, float (số thực), bool.

Vòng lặp for lặp một khối lệnh với biến đếm thay đổi. Sketch dưới cho LED nháy với chu kỳ tăng dần từ 100 ms đến 1000 ms:

BlinkRates.inoChạy thử trên Wokwi ↗
// BlinkRates.ino -- a for loop steps the blink period from 100 ms to 1000 ms
const int LED = 9;

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  for (int i = 100; i <= 1000; i = i + 100) {
    digitalWrite(LED, HIGH);
    delay(i);                      // on for i milliseconds
    digitalWrite(LED, LOW);
    delay(i);                      // off for i milliseconds
  }                                // after i = 1000, loop() starts again at 100
}

Nguồn: Viết cho trang này dựa trên bài giảng, dùng tự do

Diễn biến: i = 100 thỏa điều kiện i ≤ 1000 nên khối lệnh chạy (sáng 100 ms, tắt 100 ms); cuối vòng i tăng thêm 100; lặp lại tới khi i vượt 1000, lúc đó loop() kết thúc và bắt đầu lại.

4. Đọc nút nhấn

Chân đầu vào không được nối với gì sẽ "lơ lửng" và đọc ra giá trị ngẫu nhiên. Có hai cách cố định mức của nó khi nút chưa nhấn:

  • Điện trở kéo xuống (pull-down) 10 kΩ ra GND: nút nối chân với 5 V, nhấn thì đọc HIGH.
  • Điện trở kéo lên bên trong: pinMode(2, INPUT_PULLUP) bật điện trở khoảng 20 kΩ lên 5 V có sẵn trong chip; nút nối chân với GND, nhấn thì đọc LOW. Không cần điện trở ngoài.
Button.inoChạy thử trên Wokwi ↗
/*
  Button

  Turns on and off a light emitting diode(LED) connected to digital pin 13,
  when pressing a pushbutton attached to pin 2.

  The circuit:
  - LED attached from pin 13 to ground through 220 ohm resistor
  - pushbutton attached to pin 2 from +5V
  - 10K resistor attached to pin 2 from ground

  - Note: on most Arduinos there is already an LED on the board
    attached to pin 13.

  created 2005
  by DojoDave <http://www.0j0.org>
  modified 30 Aug 2011
  by Tom Igoe

  This example code is in the public domain.

  https://docs.arduino.cc/built-in-examples/digital/Button/
*/

// constants won't change. They're used here to set pin numbers:
const int buttonPin = 2;  // the number of the pushbutton pin
const int ledPin = 13;    // the number of the LED pin

// variables will change:
int buttonState = 0;  // variable for reading the pushbutton status

void setup() {
  // initialize the LED pin as an output:
  pinMode(ledPin, OUTPUT);
  // initialize the pushbutton pin as an input:
  pinMode(buttonPin, INPUT);
}

void loop() {
  // read the state of the pushbutton value:
  buttonState = digitalRead(buttonPin);

  // check if the pushbutton is pressed. If it is, the buttonState is HIGH:
  if (buttonState == HIGH) {
    // turn LED on:
    digitalWrite(ledPin, HIGH);
  } else {
    // turn LED off:
    digitalWrite(ledPin, LOW);
  }
}

InputPullupSerial.inoChạy thử trên Wokwi ↗
/*
  Input Pull-up Serial

  This example demonstrates the use of pinMode(INPUT_PULLUP). It reads a digital
  input on pin 2 and prints the results to the Serial Monitor.

  The circuit:
  - momentary switch attached from pin 2 to ground
  - built-in LED on pin 13

  Unlike pinMode(INPUT), there is no pull-down resistor necessary. An internal
  20K-ohm resistor is pulled to 5V. This configuration causes the input to read
  HIGH when the switch is open, and LOW when it is closed.

  created 14 Mar 2012
  by Scott Fitzgerald

  This example code is in the public domain.

  https://docs.arduino.cc/built-in-examples/digital/InputPullupSerial/
*/

void setup() {
  //start serial connection
  Serial.begin(9600);
  //configure pin 2 as an input and enable the internal pull-up resistor
  pinMode(2, INPUT_PULLUP);
  pinMode(13, OUTPUT);
}

void loop() {
  //read the pushbutton value into a variable
  int sensorVal = digitalRead(2);
  //print out the value of the pushbutton
  Serial.println(sensorVal);

  // Keep in mind the pull-up means the pushbutton's logic is inverted. It goes
  // HIGH when it's open, and LOW when it's pressed. Turn on pin 13 when the
  // button's pressed, and off when it's not:
  if (sensorVal == HIGH) {
    digitalWrite(13, LOW);
  } else {
    digitalWrite(13, HIGH);
  }
}

5. Nhấp nháy mà không dùng delay()

delay() làm vi điều khiển đứng yên, không đọc được nút hay cảm biến trong lúc chờ. Cách chuẩn là so sánh thời gian bằng millis() (số mili giây từ lúc khởi động):

BlinkWithoutDelay.inoChạy thử trên Wokwi ↗
/*
  Blink without Delay

  Turns on and off a light emitting diode (LED) connected to a digital pin,
  without using the delay() function. This means that other code can run at the
  same time without being interrupted by the LED code.

  The circuit:
  - Use the onboard LED.
  - Note: Most Arduinos have an on-board LED you can control. On the UNO, MEGA
    and ZERO it is attached to digital pin 13, on MKR1000 on pin 6. LED_BUILTIN
    is set to the correct LED pin independent of which board is used.
    If you want to know what pin the on-board LED is connected to on your
    Arduino model, check the Technical Specs of your board at:
    https://docs.arduino.cc/hardware/

  created 2005
  by David A. Mellis
  modified 8 Feb 2010
  by Paul Stoffregen
  modified 11 Nov 2013
  by Scott Fitzgerald
  modified 9 Jan 2017
  by Arturo Guadalupi

  This example code is in the public domain.

  https://docs.arduino.cc/built-in-examples/digital/BlinkWithoutDelay/
*/

// constants won't change. Used here to set a pin number:
const int ledPin = LED_BUILTIN;  // the number of the LED pin

// Variables will change:
int ledState = LOW;  // ledState used to set the LED

// Generally, you should use "unsigned long" for variables that hold time
// The value will quickly become too large for an int to store
unsigned long previousMillis = 0;  // will store last time LED was updated

// constants won't change:
const long interval = 1000;  // interval at which to blink (milliseconds)

void setup() {
  // set the digital pin as output:
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // here is where you'd put code that needs to be running all the time.

  // check to see if it's time to blink the LED; that is, if the difference
  // between the current time and last time you blinked the LED is bigger than
  // the interval at which you want to blink the LED.
  unsigned long currentMillis = millis();

  if (currentMillis - previousMillis >= interval) {
    // save the last time you blinked the LED
    previousMillis = currentMillis;

    // if the LED is off turn it on and vice-versa:
    if (ledState == LOW) {
      ledState = HIGH;
    } else {
      ledState = LOW;
    }

    // set the LED with the ledState of the variable:
    digitalWrite(ledPin, ledState);
  }
}

Đáp án và hướng dẫn

1. R = (5 − 3)/0,010 = 200 Ω; chọn 220 Ω (khoảng 9 mA).

2. Phát hiện cạnh nhấn (từ HIGH sang LOW), không phải mức, và chống dội phím (bounce) bằng một khoảng chờ ngắn:

const int BTN = 2, LED = 9;
bool ledOn = false;
int lastState = HIGH;
void setup() { pinMode(BTN, INPUT_PULLUP); pinMode(LED, OUTPUT); }
void loop() {
  int s = digitalRead(BTN);
  if (lastState == HIGH && s == LOW) {   // just pressed
    ledOn = !ledOn;
    digitalWrite(LED, ledOn);
    delay(30);                            // ignore contact bounce
  }
  lastState = s;
}

3. millis() quay vòng về 0 sau khoảng 49,7 ngày (2³² ms). Phép trừ giữa hai số unsigned long vẫn cho đúng khoảng thời gian kể cả khi đã quay vòng; còn phép cộng previousMillis + interval có thể tràn và làm điều kiện sai.

Beyond the on-board LED: wire an external LED on a breadboard, size its current-limiting resistor, use variables, constants and for loops, read a push button, and blink without blocking the program with delay().

1. Breadboard and LED

A breadboard lets you build circuits without soldering. The two long rows at the edges (usually marked red and blue) are the power and ground rails, connected along their length; in the middle each column of 5 holes is connected, and the centre gap separates the two halves.

An LED is polarized: the long leg is the anode (+), the short leg the cathode (−). Plugged in backwards it stays dark (but is not damaged at 5 V with a series resistor).

2. Why the resistor

An LED is a diode: once it conducts, its voltage is almost constant (VF about 1.8–2.2 V for red, about 3 V for blue and white), so the current is limited only by the series resistor:

$$R=\frac{V_{\text{supply}}-V_F}{I}$$

An ATmega328P pin has an absolute maximum of 40 mA and should stay below about 20 mA. With VF = 2 V and I = 15 mA, R = 200 Ω; the standard 220 Ω gives about 14 mA.

const int LED = 9; declares a read-only integer. Naming the pin number makes code readable and means a pin change is a one-line edit. An int holds an integer; other common types are long, float (real numbers) and bool.

A for loop repeats a block while a counter changes. The sketch below blinks with a period growing from 100 ms to 1000 ms:

BlinkRates.inoTry it on Wokwi ↗
// BlinkRates.ino -- a for loop steps the blink period from 100 ms to 1000 ms
const int LED = 9;

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  for (int i = 100; i <= 1000; i = i + 100) {
    digitalWrite(LED, HIGH);
    delay(i);                      // on for i milliseconds
    digitalWrite(LED, LOW);
    delay(i);                      // off for i milliseconds
  }                                // after i = 1000, loop() starts again at 100
}

Source: Written for this page from the lectures, free to use

Step by step: i = 100 satisfies i ≤ 1000, so the block runs (on 100 ms, off 100 ms); at the end i grows by 100; this repeats until i passes 1000, then loop() ends and starts again.

4. Reading a push button

An input pin connected to nothing "floats" and reads random values. Two ways to fix its level when the button is not pressed:

  • A pull-down resistor of 10 kΩ to GND: the button connects the pin to 5 V and reads HIGH when pressed.
  • The internal pull-up: pinMode(2, INPUT_PULLUP) enables a roughly 20 kΩ resistor to 5 V inside the chip; the button connects the pin to GND and reads LOW when pressed. No external resistor needed.

5. Blinking without delay()

delay() freezes the microcontroller; it cannot read a button or sensor while waiting. The standard approach compares times with millis() (milliseconds since start-up):

BlinkWithoutDelay.inoTry it on Wokwi ↗
/*
  Blink without Delay

  Turns on and off a light emitting diode (LED) connected to a digital pin,
  without using the delay() function. This means that other code can run at the
  same time without being interrupted by the LED code.

  The circuit:
  - Use the onboard LED.
  - Note: Most Arduinos have an on-board LED you can control. On the UNO, MEGA
    and ZERO it is attached to digital pin 13, on MKR1000 on pin 6. LED_BUILTIN
    is set to the correct LED pin independent of which board is used.
    If you want to know what pin the on-board LED is connected to on your
    Arduino model, check the Technical Specs of your board at:
    https://docs.arduino.cc/hardware/

  created 2005
  by David A. Mellis
  modified 8 Feb 2010
  by Paul Stoffregen
  modified 11 Nov 2013
  by Scott Fitzgerald
  modified 9 Jan 2017
  by Arturo Guadalupi

  This example code is in the public domain.

  https://docs.arduino.cc/built-in-examples/digital/BlinkWithoutDelay/
*/

// constants won't change. Used here to set a pin number:
const int ledPin = LED_BUILTIN;  // the number of the LED pin

// Variables will change:
int ledState = LOW;  // ledState used to set the LED

// Generally, you should use "unsigned long" for variables that hold time
// The value will quickly become too large for an int to store
unsigned long previousMillis = 0;  // will store last time LED was updated

// constants won't change:
const long interval = 1000;  // interval at which to blink (milliseconds)

void setup() {
  // set the digital pin as output:
  pinMode(ledPin, OUTPUT);
}

void loop() {
  // here is where you'd put code that needs to be running all the time.

  // check to see if it's time to blink the LED; that is, if the difference
  // between the current time and last time you blinked the LED is bigger than
  // the interval at which you want to blink the LED.
  unsigned long currentMillis = millis();

  if (currentMillis - previousMillis >= interval) {
    // save the last time you blinked the LED
    previousMillis = currentMillis;

    // if the LED is off turn it on and vice-versa:
    if (ledState == LOW) {
      ledState = HIGH;
    } else {
      ledState = LOW;
    }

    // set the LED with the ledState of the variable:
    digitalWrite(ledPin, ledState);
  }
}

This is the basis of every project that does several things at once, such as measuring distance while driving motors.

6. Exercises

  1. A blue LED has VF = 3.0 V. With a 5 V supply and 10 mA, what resistor do you need?
  2. Write a sketch: each press of a button (INPUT_PULLUP on pin 2) toggles the LED on pin 9.
  3. In BlinkWithoutDelay, why write currentMillis - previousMillis >= interval rather than currentMillis >= previousMillis + interval?
Answers and hints

1. R = (5 − 3)/0.010 = 200 Ω; use 220 Ω (about 9 mA).

2. Detect the press edge (HIGH to LOW), not the level, and debounce with a short wait:

const int BTN = 2, LED = 9;
bool ledOn = false;
int lastState = HIGH;
void setup() { pinMode(BTN, INPUT_PULLUP); pinMode(LED, OUTPUT); }
void loop() {
  int s = digitalRead(BTN);
  if (lastState == HIGH && s == LOW) {   // just pressed
    ledOn = !ledOn;
    digitalWrite(LED, ledOn);
    delay(30);                            // ignore contact bounce
  }
  lastState = s;
}

3. millis() wraps back to 0 after about 49.7 days (2³² ms). Subtracting two unsigned long values still gives the right interval across the wrap; the sum previousMillis + interval can overflow and make the test wrong.
