Chương trình Arduino được gọi là sketch. Bài này đi từng dòng qua sketch đầu tiên, Blink, rồi dùng Serial Monitor để Arduino "nói chuyện" với máy tính.

1. Blink: chương trình đầu tiên

Mở File → Examples → 01.Basics → Blink trong IDE, hoặc dùng bản dưới đây. Bấm nút mũi tên (Upload): LED trên bo (chân 13) sẽ nhấp nháy mỗi giây.

Blink.inoChạy thử trên Wokwi ↗
/*
  Blink

  Turns an LED on for one second, then off for one second, repeatedly.

  Most Arduinos have an on-board LED you can control. On the UNO, MEGA and ZERO
  it is attached to digital pin 13, on MKR1000 on pin 6. LED_BUILTIN is set to
  the correct LED pin independent of which board is used.
  If you want to know what pin the on-board LED is connected to on your Arduino
  model, check the Technical Specs of your board at:
  https://docs.arduino.cc/hardware/

  modified 8 May 2014
  by Scott Fitzgerald
  modified 2 Sep 2016
  by Arturo Guadalupi
  modified 8 Sep 2016
  by Colby Newman

  This example code is in the public domain.

  https://docs.arduino.cc/built-in-examples/basics/Blink/
*/

// the setup function runs once when you press reset or power the board
void setup() {
  // initialize digital pin LED_BUILTIN as an output.
  pinMode(LED_BUILTIN, OUTPUT);
}

// the loop function runs over and over again forever
void loop() {
  digitalWrite(LED_BUILTIN, HIGH);  // change state of the LED by setting the pin to the HIGH voltage level
  delay(1000);                      // wait for a second
  digitalWrite(LED_BUILTIN, LOW);   // change state of the LED by setting the pin to the LOW voltage level
  delay(1000);                      // wait for a second
}

Nguồn: Mã gốc của Arduino, phạm vi công cộng (CC0)

2. Đọc từng phần

  • Chú thích: đoạn giữa /* và */ là chú thích nhiều dòng; mọi thứ sau // đến hết dòng là chú thích một dòng. Trình biên dịch bỏ qua chúng, chúng chỉ để người đọc hiểu code.
  • void setup(): chạy một lần khi bật nguồn hay nhấn reset. Đặt ở đây các thiết lập ban đầu: hướng của chân, tốc độ giao tiếp.
  • void loop(): chạy lặp lại mãi sau setup(). Mọi sketch đều phải có cả hai hàm này.
  • pinMode(chân, OUTPUT): mọi chân mặc định là đầu vào; muốn xuất 5 V hay 0 V thì phải đặt là OUTPUT. LED_BUILTIN là tên có sẵn, trình biên dịch đổi thành số chân của LED trên bo (13 trên Uno).
  • digitalWrite(chân, HIGH/LOW): đặt chân lên 5 V (HIGH) hoặc 0 V (LOW). Chân giữ trạng thái đó cho đến lệnh kế tiếp.
  • delay(ms): dừng chương trình trong số mili giây cho trước. delay(1000) là 1 giây.

Mỗi câu lệnh kết thúc bằng dấu chấm phẩy; khối lệnh nằm trong dấu ngoặc nhọn. Thiếu một dấu ; là lỗi biên dịch phổ biến nhất của người mới.

3. Serial Monitor: Arduino in ra máy tính

Arduino không có màn hình, nhưng có thể gửi chữ về máy tính qua cổng USB. Đây là công cụ gỡ lỗi quan trọng nhất.

HelloSerial.inoChạy thử trên Wokwi ↗
// HelloSerial.ino -- print a message and a running counter to the Serial Monitor
// Open Tools > Serial Monitor and choose 9600 baud.
unsigned long count = 0;

void setup() {
  Serial.begin(9600);              // start serial communication at 9600 bit/s
  Serial.println("Hello, Arduino!");
}

void loop() {
  Serial.print("t = ");
  Serial.print(count);
  Serial.println(" s");
  count++;
  delay(1000);                     // wait one second
}

Nguồn: Viết cho trang này dựa trên bài giảng, dùng tự do

Serial.begin(9600) mở kết nối với tốc độ 9600 baud (bit mỗi giây). Mở Tools → Serial Monitor và chọn đúng 9600 ở góc dưới; chọn sai tốc độ sẽ thấy ký tự rác. Serial.print() in không xuống dòng, Serial.println() in rồi xuống dòng.

4. Quy trình làm việc

  1. Viết hoặc dán code.
  2. Verify (nút ✓): biên dịch, báo lỗi cú pháp nếu có.
  3. Upload (nút →): biên dịch rồi nạp vào bo.
  4. Mở Serial Monitor nếu sketch có dùng Serial.

5. Bài tập

  1. Sửa Blink để LED sáng 0,2 s và tắt 0,8 s.
  2. Sửa Blink để LED nháy tín hiệu SOS (··· −−− ···).
  3. Trong HelloSerial, biến count khai báo kiểu unsigned long. Nếu đổi thành int thì sau bao lâu có vấn đề?
Đáp án và hướng dẫn

1. Đổi hai lệnh delay thành delay(200); và delay(800);. Chu kỳ vẫn là 1 s.

2. Viết một hàm nhấp nháy:

void flash(int onMs) {
  digitalWrite(LED_BUILTIN, HIGH); delay(onMs);
  digitalWrite(LED_BUILTIN, LOW);  delay(200);
}
void loop() {
  for (int i = 0; i < 3; i++) flash(200);   // S: dot dot dot
  for (int i = 0; i < 3; i++) flash(600);   // O: dash dash dash
  for (int i = 0; i < 3; i++) flash(200);   // S
  delay(2000);
}

3. Trên Uno, int là 16 bit có dấu, lớn nhất 32 767. Mỗi giây tăng 1, nên sau 32 767 s (khoảng 9,1 giờ) giá trị tràn thành −32 768. unsigned long (32 bit) chạy được 2³² − 1 s, hơn 136 năm.

An Arduino program is called a sketch. This lesson walks line by line through the first sketch, Blink, then uses the Serial Monitor so the Arduino can "talk" to the computer.

1. Blink: the first program

Open File → Examples → 01.Basics → Blink in the IDE, or use the copy below. Press the arrow button (Upload): the on-board LED (pin 13) blinks once a second.

2. Reading it part by part

  • Comments: text between /* and */ is a multi-line comment; everything after // to the end of the line is a single-line comment. The compiler ignores them; they are for human readers.
  • void setup(): runs once at power-up or reset. Put one-time settings here: pin directions, communication speed.
  • void loop(): runs over and over after setup(). Every sketch must have both functions.
  • pinMode(pin, OUTPUT): all pins are inputs by default; to output 5 V or 0 V a pin must be set to OUTPUT. LED_BUILTIN is a predefined name the compiler turns into the pin number of the on-board LED (13 on the Uno).
  • digitalWrite(pin, HIGH/LOW): sets the pin to 5 V (HIGH) or 0 V (LOW). The pin stays there until the next command.
  • delay(ms): pauses the program for the given number of milliseconds. delay(1000) is one second.

Every statement ends with a semicolon; blocks of code sit inside curly braces. A missing ; is the most common beginner compile error.

3. The Serial Monitor: printing to the computer

The Arduino has no screen, but it can send text back to the computer over USB. This is the most important debugging tool.

HelloSerial.inoTry it on Wokwi ↗
// HelloSerial.ino -- print a message and a running counter to the Serial Monitor
// Open Tools > Serial Monitor and choose 9600 baud.
unsigned long count = 0;

void setup() {
  Serial.begin(9600);              // start serial communication at 9600 bit/s
  Serial.println("Hello, Arduino!");
}

void loop() {
  Serial.print("t = ");
  Serial.print(count);
  Serial.println(" s");
  count++;
  delay(1000);                     // wait one second
}

Source: Written for this page from the lectures, free to use

Serial.begin(9600) opens the link at 9600 baud (bits per second). Open Tools → Serial Monitor and choose 9600 in the corner; the wrong speed shows garbage characters. Serial.print() prints without a new line, Serial.println() prints and then starts a new line.

4. The workflow

  1. Write or paste the code.
  2. Verify (✓ button): compiles and reports any syntax errors.
  3. Upload (→ button): compiles and loads the program onto the board.
  4. Open the Serial Monitor if the sketch uses Serial.

5. Exercises

  1. Change Blink so the LED is on for 0.2 s and off for 0.8 s.
  2. Change Blink so the LED flashes SOS (··· −−− ···).
  3. In HelloSerial, count is declared unsigned long. If it were an int, when would trouble start?
Answers and hints

1. Change the two delays to delay(200); and delay(800);. The period is still 1 s.

2. Write a flash function:

void flash(int onMs) {
  digitalWrite(LED_BUILTIN, HIGH); delay(onMs);
  digitalWrite(LED_BUILTIN, LOW);  delay(200);
}
void loop() {
  for (int i = 0; i < 3; i++) flash(200);   // S: dot dot dot
  for (int i = 0; i < 3; i++) flash(600);   // O: dash dash dash
  for (int i = 0; i < 3; i++) flash(200);   // S
  delay(2000);
}

3. On the Uno an int is a signed 16-bit number with a maximum of 32 767. Counting one per second, it overflows to −32 768 after 32 767 s (about 9.1 hours). An unsigned long (32 bits) lasts 2³² − 1 s, over 136 years.
