Về phần thực hành này

Phần 4 đi theo các bài thực hành của học phần Semiconductor Device Design (GS. Jinyoung Hwang, Korea Aerospace University) và bộ bài TCAD Laboratory của G. Betti Beneventi (University of Bologna) được dùng trong môn học. Cấu trúc, thông số và trình tự giải bám theo bài giảng; mã lệnh được viết lại, chú thích và kiểm tra cú pháp theo tài liệu Sentaurus. Từ khóa có thể khác giữa các phiên bản, nên luôn đối chiếu với hướng dẫn sử dụng đi kèm phiên bản bạn dùng.

Bài thực hành đầu tiên: dựng một tiếp giáp pn đột ngột, quét đặc tuyến I-V và đọc giản đồ vùng năng lượng. Đây là "hello world" của TCAD, đủ đơn giản để kiểm tra mọi kết quả bằng công thức trong sách.

1. Cấu trúc và cây thí nghiệm

Cấu trúc trong bài giảng là một khối 1 µm × 4 µm: lớp p dày 2 µm ở trên (từ y = 0 đến 2 µm), lớp n dày 2 µm ở dưới, cả hai pha tạp 10¹⁶ cm⁻³. Tiếp xúc p ở cạnh trên, tiếp xúc n ở cạnh dưới. Trong Sentaurus Workbench (SWB), tạo dự án gồm một công cụ SDE và một công cụ SDevice, rồi thêm các tham số:

Tham sốGiá trị gợi ýDùng ở
materialSilicon, Germanium, GaAsSDE
Wp, Wn2, 2 (µm)SDE
NA, ND1e16; thêm 1e18 để so sánhSDE
SRH0, 1SDevice
V_start, V_stop−5, 1 (V)SDevice

Mỗi tổ hợp giá trị là một thí nghiệm (một hàng trong cây). Khi tiền xử lý (Ctrl+P), SWB thay mọi chuỗi @tên@ trong file lệnh bằng giá trị của hàng đó, nên một file lệnh phục vụ toàn bộ cây.

2. File SDE

;; pn_dvs.cmd -- ideal step pn junction, 1 um wide, p on top of n
;; axes: x = width, y = depth (y grows downward)
(sde:clear)
(sdegeo:set-default-boolean "ABA")          ; a new region overwrites old ones

;; ---- parameters taken from the SWB tree ----
(define MAT  "@material@")                  ; Silicon, Germanium or GaAs
(define W    1.0)                           ; width [um]
(define Wp   @Wp@)                          ; p-layer thickness [um], e.g. 2
(define Wn   @Wn@)                          ; n-layer thickness [um], e.g. 2
(define NA   @NA@)                          ; acceptors [cm-3], e.g. 1e16
(define ND   @ND@)                          ; donors    [cm-3], e.g. 1e16
(define Ytot (+ Wp Wn))

;; ---- geometry: two rectangles of the same material ----
(sdegeo:create-rectangle (position 0 0 0)  (position W Wp 0)   MAT "R.p")
(sdegeo:create-rectangle (position 0 Wp 0) (position W Ytot 0) MAT "R.n")

;; ---- contacts: declare a set, make it current, attach it to an edge ----
(sdegeo:define-contact-set "p_contact" 4 (color:rgb 1 0 0) "##")
(sdegeo:define-contact-set "n_contact" 4 (color:rgb 0 0 1) "##")
(sdegeo:set-current-contact-set "p_contact")
(sdegeo:define-2d-contact (find-edge-id (position (/ W 2) 0 0)) "p_contact")
(sdegeo:set-current-contact-set "n_contact")
(sdegeo:define-2d-contact (find-edge-id (position (/ W 2) Ytot 0)) "n_contact")

;; ---- doping: one constant profile per region ----
(sdedr:define-constant-profile "P.acc" "BoronActiveConcentration" NA)
(sdedr:define-constant-profile-region "Pl.acc" "P.acc" "R.p")
(sdedr:define-constant-profile "P.don" "PhosphorusActiveConcentration" ND)
(sdedr:define-constant-profile-region "Pl.don" "P.don" "R.n")

;; ---- mesh: coarse everywhere, fine within +-0.3 um of the junction ----
;; refinement-size arguments: xmax ymax xmin ymin  [um]
(sdedr:define-refeval-window "Win.all" "Rectangle" (position 0 0 0) (position W Ytot 0))
(sdedr:define-refinement-size "Size.all" 0.25 0.2 0.05 0.01)
(sdedr:define-refinement-placement "Ref.all" "Size.all" "Win.all")
(sdedr:define-refeval-window "Win.j" "Rectangle"
   (position 0 (- Wp 0.3) 0) (position W (+ Wp 0.3) 0))
(sdedr:define-refinement-size "Size.j" 0.25 0.01 0.05 0.002)
(sdedr:define-refinement-placement "Ref.j" "Size.j" "Win.j")

;; ---- build the mesh; n@node@ names the output after this SWB node ----
(sde:build-mesh "snmesh" "-a -c boxmethod" "n@node@")

Ba điểm người mới hay vấp:

  • Trong SDE, chú thích bắt đầu bằng dấu chấm phẩy ;; trong SDevice là dấu sao * hoặc #.
  • find-edge-id chọn cạnh đi qua điểm cho trước. Nếu điểm rơi đúng vào đỉnh hoặc không nằm trên cạnh nào, tiếp xúc sẽ không được tạo mà không báo lỗi rõ ràng; hãy mở n*_msh.tdr để kiểm tra.
  • Tên pha tạp BoronActiveConcentration và PhosphorusActiveConcentration là acceptor và donor trong mọi vật liệu bán dẫn, nên cùng file này chạy được cho Ge và GaAs.

3. File SDevice và file tham số

* pn_des.cmd -- DC sweep of the pn junction
File {
  Grid      = "@tdr@"             * mesh + doping written by SDE for this experiment
  Parameter = "@parameter@"       * the project parameter file (sdevice.par)
  Plot      = "n@node@_des.tdr"   * fields, bands and densities (snapshots)
  Current   = "n@node@_des.plt"   * terminal voltages and currents
  Output    = "n@node@_des.log"
}

Electrode {                        * names must match the SDE contact names
  { Name = "p_contact"  Voltage = 0.0 }
  { Name = "n_contact"  Voltage = 0.0 }
}

Physics {
  AreaFactor = 1                   * 2D current is per um of depth; scale it here
  Mobility ( DopingDependence )
  Recombination (
  #if @SRH@ == 1                   * SWB switch: 0 = ideal diode, 1 = with SRH
    SRH
  #endif
  )
}

Plot {
  DopingConcentration  SpaceCharge  ElectricField/Vector  Potential
  ConductionBandEnergy  ValenceBandEnergy  eQuasiFermiEnergy  hQuasiFermiEnergy
  eDensity  hDensity  eCurrent/Vector  hCurrent/Vector  SRHRecombination
}

Math {
  Extrapolate                      * start each step from an extrapolated guess
  Derivatives                      * full Jacobian for Newton
  -RelErrControl
  Digits     = 5                   * relative error 1e-5
  Iterations = 20                  * Newton iterations per step
  Method     = ParDiSo             * direct linear solver
  CNormPrint                       * print where the error is largest
}

Solve {
  Coupled { Poisson }                                   * 1) equilibrium guess
  Coupled { Poisson Electron Hole }                     * 2) full equilibrium

  Quasistationary (                                     * 3) reverse branch
    InitialStep = 0.01  MaxStep = 0.05  MinStep = 1e-5
    Goal { Name = "p_contact"  Voltage = @V_start@ }
    Plot { Range = (0, 1)  Intervals = 2 }
  ) { Coupled { Poisson Electron Hole } }

  Quasistationary (                                     * 4) back to 0 V
    InitialStep = 0.05  MaxStep = 0.1  MinStep = 1e-5
    Goal { Name = "p_contact"  Voltage = 0 }
  ) { Coupled { Poisson Electron Hole } }

  NewCurrentPrefix = "fwd_"                             * 5) separate file for the
  Quasistationary (                                     *    forward branch
    InitialStep = 0.01  MaxStep = 0.02  MinStep = 1e-5
    Goal { Name = "p_contact"  Voltage = @V_stop@ }
    Plot { Range = (0, 1)  Intervals = 10 }
  ) { Coupled { Poisson Electron Hole } }
}

Một vài lựa chọn đáng chú ý. Khối #if @SRH@ == 1 ... #endif được SWB xử lý trước khi chạy, nên cùng một file cho ra hai phiên bản có và không có tái hợp SRH. AreaFactor nhân dòng điện: mô phỏng 2D cho dòng trên mỗi µm chiều sâu, nên muốn dòng của linh kiện thật thì đặt AreaFactor bằng chiều sâu tính theo µm. Quét ngược trước, về 0 V rồi mới quét thuận giúp mỗi nhánh bắt đầu từ một nghiệm đã hội tụ; NewCurrentPrefix ghi nhánh thuận ra file .plt riêng cho dễ vẽ.

SWB cần một file tham số, dù rỗng. Muốn xem và sửa tham số mặc định của từng vật liệu thì xuất chúng ra:

# in the project folder, collect default parameters for each material
sdevice -P:Silicon    >  sdevice.par
sdevice -P:Germanium  >> sdevice.par
sdevice -P:GaAs       >> sdevice.par
# then delete the log header that each call prints, keeping only the
# blocks  Material = "Silicon" { ... }  and so on

4. Chạy và kiểm tra hội tụ

  1. Ctrl+P để tiền xử lý tất cả các nút.
  2. Chọn các nút SDE, Ctrl+R để chạy; nút chuyển sang màu vàng là xong.
  3. Chọn các nút SDevice, Ctrl+R.
  4. Mở file .out hoặc .log của nút SDevice: mỗi bước in ra sai số chuẩn hóa của từng phương trình; hội tụ khi sai số nhỏ hơn 1. Nhờ CNormPrint, file còn ghi tọa độ nơi sai số lớn nhất, chỗ cần làm mịn lưới nếu bị kẹt.

5. Đọc kết quả và đối chiếu với lý thuyết

Giản đồ vùng. Mở file .tdr ở 0 V trong Sentaurus Visual, cắt một đường dọc theo y và vẽ ConductionBandEnergy, ValenceBandEnergy và hai mức giả Fermi. Ở cân bằng hai mức giả Fermi trùng nhau và phẳng; độ cong của vùng là thế xây dựng:

$$V_{bi}=\frac{kT}{q}\ln\frac{N_A N_D}{n_i^2}$$

Bài thực hành của Betti Beneventi cho \(V_{bi}\approx 697\) mV khi \(N_A=N_D=10^{16}\) cm⁻³ và khoảng 937 mV khi tăng lên 10¹⁸ cm⁻³; với Ge (\(n_i\approx 2{,}4\times10^{13}\) cm⁻³) và GaAs (\(n_i\approx 1{,}8\times10^{6}\) cm⁻³) bài đó cho khoảng 434 mV và 1,29 V, là các giá trị ứng với pha tạp 10¹⁷ cm⁻³ (ở 10¹⁶ cm⁻³ công thức cho khoảng 0,31 V và 1,16 V). Đó cũng gần đúng là "điện áp mở" đọc được trên đặc tuyến thuận tuyến tính.

Vùng nghèo. Với \(N_A=N_D=10^{16}\) cm⁻³ trong Si:

$$W=\sqrt{\frac{2\varepsilon_s V_{bi}}{q}\left(\frac{1}{N_A}+\frac{1}{N_D}\right)}\approx 0{,}42\ \mu\text{m},\qquad E_{max}=\frac{qN_A x_p}{\varepsilon_s}\approx 3{,}3\times10^{4}\ \text{V/cm}$$

Vẽ SpaceCharge và ElectricField dọc theo y để so: vùng điện tích là hai khối chữ nhật đối xứng hai bên y = 2 µm, điện trường có dạng tam giác.

Đặc tuyến I-V. Trong Inspect, đặt p_contact OuterVoltage lên trục x và p_contact TotalCurrent lên trục y, chuyển trục y sang thang log. Phần giữa của nhánh thuận là đường thẳng 60 mV/decade (hệ số lý tưởng n = 1); ở dòng lớn đường cong bị uốn xuống do điện trở nối tiếp. Khi bật SRH, dòng ngược tăng và đoạn điện áp thấp của nhánh thuận dốc ít hơn (xem bài sau).

Mật độ hạt dẫn. Vẽ eDensity và hDensity ở thang log khi phân cực thuận: phía p, electron thiểu số giảm theo hàm mũ khi đi xa vùng nghèo, đúng như mô hình khuếch tán.

6. Trường hợp điện trở

Đổi pha tạp lớp trên từ acceptor sang donor (thêm tham số p_type nhận giá trị BoronActiveConcentration hoặc PhosphorusActiveConcentration và đưa nó vào lệnh define-constant-profile). Khi đó toàn khối là n đồng nhất: không còn tiếp giáp, không còn vùng điện tích, chỉ có dòng trôi, nên I-V là đường thẳng và các mức giả Fermi nghiêng đều từ tiếp xúc này sang tiếp xúc kia. Kiểm tra bằng \(R=\rho L/A\): với Si n 10¹⁶ cm⁻³ (\(\rho\approx 0{,}5\ \Omega\cdot\)cm), dài 4 µm, mặt cắt 1 µm × 1 µm, dòng ở 1 V cỡ 5 × 10⁻⁵ A (trên mỗi µm chiều sâu).

Góc nhìn Ga₂O₃

β-Ga₂O₃ chưa có pha tạp loại p hiệu quả, nên không có tiếp giáp pn đồng chất như bài này. Diode pn Ga₂O₃ trong thực tế là dị chất, phổ biến nhất là p-NiO/n-Ga₂O₃ (ví dụ Gong và cộng sự, 2020). Quy trình mô phỏng giữ nguyên, chỉ thêm một vùng vật liệu thứ hai với ái lực điện tử, độ rộng vùng cấm riêng và kiểm tra độ lệch vùng tại mặt phân cách trên giản đồ vùng.

7. Bài tập

  1. So sánh \(V_{bi}\) đọc từ giản đồ vùng với công thức cho bốn tổ hợp: Si 10¹⁶/10¹⁶, Si 10¹⁸/10¹⁸, Ge và GaAs.
  2. Từ ElectricField, đo bề rộng vùng nghèo ở 0 V và −5 V, rồi so với \(W\propto\sqrt{V_{bi}-V}\).
  3. Đo độ dốc nhánh thuận (mV/decade) có và không có SRH ở 0,2 V và 0,5 V.
  4. Làm trường hợp điện trở, rồi giải thích vì sao các mức giả Fermi là đường thẳng.
Đáp án và hướng dẫn

Các số dưới đây là tính tay theo mô hình giải tích để bạn có mốc đối chiếu. Kết quả mô phỏng sẽ lệch vài phần trăm đến vài chục phần trăm tùy giá trị \(n_i\), mô hình thu hẹp vùng cấm, lưới và cách trích; khi lệch, hãy giải thích được vì sao.

1. \(V_{bi}=(kT/q)\ln(N_AN_D/n_i^2)\), \(kT/q=25{,}85\) mV:

Trường hợp\(n_i\) (cm⁻³)\(V_{bi}\)
Si 10¹⁶/10¹⁶1,0 × 10¹⁰ / 1,5 × 10¹⁰0,71 V / 0,69 V
Si 10¹⁸/10¹⁸1,0 × 10¹⁰ / 1,5 × 10¹⁰0,95 V / 0,93 V
Ge 10¹⁶/10¹⁶2,4 × 10¹³0,31 V
GaAs 10¹⁶/10¹⁶1,8 × 10⁶1,16 V

Trên giản đồ vùng, \(V_{bi}\) là độ chênh của \(E_C\) giữa hai vùng trung hòa (đơn vị eV, chia cho q). Giá trị mô phỏng phụ thuộc \(n_i\) mà Sentaurus dùng (xem Silicon.par) nên có thể lệch vài chục mV so với công thức. Tăng pha tạp 100 lần ở cả hai phía làm \(V_{bi}\) tăng \(2\times(kT/q)\ln 100\approx 0{,}24\) V, đúng với hiệu 0,95 − 0,71.

2. Với Si 10¹⁶/10¹⁶ và \(V_{bi}\approx 0{,}71\) V: \(W(0)\approx 0{,}43\ \mu\)m, \(W(-5\ \text{V})\approx 1{,}22\ \mu\)m. Tỉ số \(1{,}22/0{,}43=2{,}83\approx\sqrt{5{,}71/0{,}71}\). Điện trường cực đại tương ứng khoảng 3,3 × 10⁴ và 9,4 × 10⁴ V/cm. Vùng nghèo vẫn nằm gọn trong hai lớp 2 µm nên công thức còn đúng.

3. Không có SRH: khoảng 60 mV/decade (n ≈ 1) ở cả 0,2 V và 0,5 V. Có SRH: độ dốc nhỏ hơn ở điện áp thấp. Điện áp chuyển tiếp, nơi dòng tái hợp bằng dòng khuếch tán, là \(V_x=2(kT/q)\ln(J_{gr0}/J_0)\). Ước lượng với thời gian sống mặc định cỡ micro giây và lớp trung hòa ngắn (diode ngắn, \(J_0\approx 4\times10^{-10}\) A/cm², \(J_{gr0}=qn_iW/2\tau\approx 7\times10^{-9}\) A/cm²) cho \(V_x\approx 0{,}15\) V; khi đó n ≈ 1,2 ở 0,2 V và ≈ 1,0 ở 0,5 V. Thời gian sống càng ngắn, \(V_x\) càng cao và vùng n ≈ 2 càng rộng. Dòng ngược cũng tăng khoảng \(J_{gr0}/J_0\) lần (cỡ 20 lần với các số trên).

4. Khối n đồng nhất không có điện tích không gian, nên theo Poisson điện trường không đổi; \(n\) cũng không đổi. Khi đó \(J_n=n\mu_n\,\mathrm{d}E_{Fn}/\mathrm{d}x\) không đổi kéo theo \(\mathrm{d}E_{Fn}/\mathrm{d}x\) không đổi, tức \(E_{Fn}\) là đường thẳng; ở hai tiếp xúc ohmic \(E_{Fn}=E_{Fp}\), nên \(E_{Fp}\) cũng thẳng. Dòng: \(\rho=1/(qn\mu_n)\approx 0{,}5\ \Omega\cdot\)cm (với \(\mu_n\approx 1200\) cm²/V·s), \(R=\rho L/A\approx 0{,}5\times4\times10^{-4}/10^{-8}=2\times10^{4}\ \Omega\) (mặt cắt 1 µm × 1 µm = 10⁻⁸ cm²), nên \(I\approx 5\times10^{-5}\) A/µm ở 1 V, tuyến tính theo V.

About this lab series

Part 4 follows the hands-on labs of the course Semiconductor Device Design (Prof. Jinyoung Hwang, Korea Aerospace University) and the TCAD Laboratory series by G. Betti Beneventi (University of Bologna) used in the course. Structures, numbers and solve sequences follow the lectures; the code was rewritten, commented and checked against the Sentaurus documentation. Keywords can change between versions, so always check the user guide shipped with your version.

The first lab: build an abrupt pn junction, sweep its I-V characteristic and read the band diagram. This is the "hello world" of TCAD, simple enough that every result can be checked against textbook formulas.

1. Structure and experiment tree

The structure in the lecture is a 1 µm × 4 µm block: a 2 µm p layer on top (y = 0 to 2 µm) and a 2 µm n layer below, both doped 10¹⁶ cm⁻³. The p contact is on the top edge and the n contact on the bottom edge. In Sentaurus Workbench (SWB), create a project with one SDE tool and one SDevice tool and add the parameters:

ParameterSuggested valuesUsed in
materialSilicon, Germanium, GaAsSDE
Wp, Wn2, 2 (µm)SDE
NA, ND1e16; add 1e18 for comparisonSDE
SRH0, 1SDevice
V_start, V_stop−5, 1 (V)SDevice

Each combination of values is one experiment (one row in the tree). On preprocessing (Ctrl+P), SWB replaces every @name@ string in the command files with that row's value, so a single command file serves the whole tree.

;; ---- doping: one constant profile per region ----
(sdedr:define-constant-profile "P.acc" "BoronActiveConcentration" NA)
(sdedr:define-constant-profile-region "Pl.acc" "P.acc" "R.p")
(sdedr:define-constant-profile "P.don" "PhosphorusActiveConcentration" ND)
(sdedr:define-constant-profile-region "Pl.don" "P.don" "R.n")

;; ---- mesh: coarse everywhere, fine within +-0.3 um of the junction ----
;; refinement-size arguments: xmax ymax xmin ymin  [um]
(sdedr:define-refeval-window "Win.all" "Rectangle" (position 0 0 0) (position W Ytot 0))
(sdedr:define-refinement-size "Size.all" 0.25 0.2 0.05 0.01)
(sdedr:define-refinement-placement "Ref.all" "Size.all" "Win.all")
(sdedr:define-refeval-window "Win.j" "Rectangle"
   (position 0 (- Wp 0.3) 0) (position W (+ Wp 0.3) 0))
(sdedr:define-refinement-size "Size.j" 0.25 0.01 0.05 0.002)
(sdedr:define-refinement-placement "Ref.j" "Size.j" "Win.j")

;; ---- build the mesh; n@node@ names the output after this SWB node ----
(sde:build-mesh "snmesh" "-a -c boxmethod" "n@node@")

Three points that trip up beginners:

  • In SDE a comment starts with a semicolon ;; in SDevice it is an asterisk * or #.
  • find-edge-id picks the edge through the given point. If the point falls exactly on a vertex or on no edge, the contact is silently not created; open n*_msh.tdr to check.
  • The species BoronActiveConcentration and PhosphorusActiveConcentration act as acceptor and donor in any semiconductor, so the same file runs for Ge and GaAs.

3. The SDevice file and the parameter file

* pn_des.cmd -- DC sweep of the pn junction
File {
  Grid      = "@tdr@"             * mesh + doping written by SDE for this experiment
  Parameter = "@parameter@"       * the project parameter file (sdevice.par)
  Plot      = "n@node@_des.tdr"   * fields, bands and densities (snapshots)
  Current   = "n@node@_des.plt"   * terminal voltages and currents
  Output    = "n@node@_des.log"
}

Electrode {                        * names must match the SDE contact names
  { Name = "p_contact"  Voltage = 0.0 }
  { Name = "n_contact"  Voltage = 0.0 }
}

Physics {
  AreaFactor = 1                   * 2D current is per um of depth; scale it here
  Mobility ( DopingDependence )
  Recombination (
  #if @SRH@ == 1                   * SWB switch: 0 = ideal diode, 1 = with SRH
    SRH
  #endif
  )
}

Plot {
  DopingConcentration  SpaceCharge  ElectricField/Vector  Potential
  ConductionBandEnergy  ValenceBandEnergy  eQuasiFermiEnergy  hQuasiFermiEnergy
  eDensity  hDensity  eCurrent/Vector  hCurrent/Vector  SRHRecombination
}

Math {
  Extrapolate                      * start each step from an extrapolated guess
  Derivatives                      * full Jacobian for Newton
  -RelErrControl
  Digits     = 5                   * relative error 1e-5
  Iterations = 20                  * Newton iterations per step
  Method     = ParDiSo             * direct linear solver
  CNormPrint                       * print where the error is largest
}

Solve {
  Coupled { Poisson }                                   * 1) equilibrium guess
  Coupled { Poisson Electron Hole }                     * 2) full equilibrium

  Quasistationary (                                     * 3) reverse branch
    InitialStep = 0.01  MaxStep = 0.05  MinStep = 1e-5
    Goal { Name = "p_contact"  Voltage = @V_start@ }
    Plot { Range = (0, 1)  Intervals = 2 }
  ) { Coupled { Poisson Electron Hole } }

  Quasistationary (                                     * 4) back to 0 V
    InitialStep = 0.05  MaxStep = 0.1  MinStep = 1e-5
    Goal { Name = "p_contact"  Voltage = 0 }
  ) { Coupled { Poisson Electron Hole } }

  NewCurrentPrefix = "fwd_"                             * 5) separate file for the
  Quasistationary (                                     *    forward branch
    InitialStep = 0.01  MaxStep = 0.02  MinStep = 1e-5
    Goal { Name = "p_contact"  Voltage = @V_stop@ }
    Plot { Range = (0, 1)  Intervals = 10 }
  ) { Coupled { Poisson Electron Hole } }
}

A few choices worth noting. The #if @SRH@ == 1 ... #endif block is handled by SWB before the run, so one file yields two versions, with and without SRH recombination. AreaFactor multiplies the current: a 2D simulation gives current per µm of depth, so set AreaFactor to the real depth in µm to get device current. Sweeping reverse first, returning to 0 V and only then sweeping forward makes each branch start from a converged solution; NewCurrentPrefix writes the forward branch to its own .plt file for easy plotting.

SWB needs a parameter file, even an empty one. To see and edit the default parameters of each material, export them:

# in the project folder, collect default parameters for each material
sdevice -P:Silicon    >  sdevice.par
sdevice -P:Germanium  >> sdevice.par
sdevice -P:GaAs       >> sdevice.par
# then delete the log header that each call prints, keeping only the
# blocks  Material = "Silicon" { ... }  and so on

4. Running and checking convergence

  1. Ctrl+P to preprocess all nodes.
  2. Select the SDE nodes and press Ctrl+R; a node turns yellow when done.
  3. Select the SDevice nodes and press Ctrl+R.
  4. Open the SDevice node's .out or .log file: each step prints the normalized error of each equation; it has converged when the error is below 1. With CNormPrint the file also gives the coordinates of the largest error, which is where to refine the mesh if the run gets stuck.

5. Reading results and checking them against theory

Band diagram. Open the 0 V .tdr file in Sentaurus Visual, cut a line along y and plot ConductionBandEnergy, ValenceBandEnergy and both quasi-Fermi levels. At equilibrium the two quasi-Fermi levels coincide and are flat; the band bending is the built-in potential:

$$V_{bi}=\frac{kT}{q}\ln\frac{N_A N_D}{n_i^2}$$

Betti Beneventi's lab gives \(V_{bi}\approx 697\) mV for \(N_A=N_D=10^{16}\) cm⁻³ and about 937 mV at 10¹⁸ cm⁻³; for Ge (\(n_i\approx 2.4\times10^{13}\) cm⁻³) and GaAs (\(n_i\approx 1.8\times10^{6}\) cm⁻³) that lab gives about 434 mV and 1.29 V, values that correspond to 10¹⁷ cm⁻³ doping (at 10¹⁶ cm⁻³ the formula gives about 0.31 V and 1.16 V). That is also roughly the "turn-on voltage" read from the forward characteristic on a linear scale.

Depletion region. For \(N_A=N_D=10^{16}\) cm⁻³ in Si:

$$W=\sqrt{\frac{2\varepsilon_s V_{bi}}{q}\left(\frac{1}{N_A}+\frac{1}{N_D}\right)}\approx 0.42\ \mu\text{m},\qquad E_{max}=\frac{qN_A x_p}{\varepsilon_s}\approx 3.3\times10^{4}\ \text{V/cm}$$

Plot SpaceCharge and ElectricField along y to compare: the charge forms two symmetric blocks either side of y = 2 µm and the field is triangular.

I-V characteristic. In Inspect, put p_contact OuterVoltage on the x axis and p_contact TotalCurrent on the y axis, and switch y to log scale. The middle of the forward branch is a straight 60 mV/decade line (ideality factor n = 1); at high current it bends over because of series resistance. With SRH on, the reverse current rises and the low-voltage part of the forward branch is less steep (see the next lab).

Carrier densities. Plot eDensity and hDensity on a log scale under forward bias: on the p side the minority electrons decay exponentially away from the depletion region, as the diffusion model predicts.

6. The resistor case

Change the top layer from acceptor to donor (add a parameter p_type taking BoronActiveConcentration or PhosphorusActiveConcentration and use it in define-constant-profile). The whole block is then uniform n: no junction, no space charge, only drift, so the I-V is a straight line and the quasi-Fermi levels slope evenly from one contact to the other. Check with \(R=\rho L/A\): for n-Si at 10¹⁶ cm⁻³ (\(\rho\approx 0.5\ \Omega\cdot\)cm), 4 µm long, with a 1 µm × 1 µm cross-section, the current at 1 V is about 5 × 10⁻⁵ A (per µm of depth).

Ga₂O₃ perspective

β-Ga₂O₃ has no effective p-type doping yet, so a homojunction like this one does not exist. Practical Ga₂O₃ pn diodes are heterojunctions, most often p-NiO/n-Ga₂O₃ (for example Gong et al., 2020). The simulation flow is the same; you add a second material region with its own electron affinity and band gap and check the band offsets at the interface on the band diagram.

7. Exercises

  1. Compare \(V_{bi}\) read from the band diagram with the formula for four cases: Si 10¹⁶/10¹⁶, Si 10¹⁸/10¹⁸, Ge and GaAs.
  2. From ElectricField, measure the depletion width at 0 V and −5 V and compare with \(W\propto\sqrt{V_{bi}-V}\).
  3. Measure the forward slope (mV/decade) with and without SRH at 0.2 V and 0.5 V.
  4. Run the resistor case and explain why the quasi-Fermi levels are straight lines.
Answers and hints

The numbers below are hand calculations from analytical models, given as reference points. Simulation results will differ by a few to a few tens of percent depending on the \(n_i\) value, band-gap narrowing, mesh and extraction method; when they differ, be able to say why.

1. \(V_{bi}=(kT/q)\ln(N_AN_D/n_i^2)\), \(kT/q=25.85\) mV:

Case\(n_i\) (cm⁻³)\(V_{bi}\)
Si 10¹⁶/10¹⁶1.0 × 10¹⁰ / 1.5 × 10¹⁰0.71 V / 0.69 V
Si 10¹⁸/10¹⁸1.0 × 10¹⁰ / 1.5 × 10¹⁰0.95 V / 0.93 V
Ge 10¹⁶/10¹⁶2.4 × 10¹³0.31 V
GaAs 10¹⁶/10¹⁶1.8 × 10⁶1.16 V

On the band diagram, \(V_{bi}\) is the step in \(E_C\) between the two neutral regions (in eV, divided by q). The simulated value depends on the \(n_i\) Sentaurus uses (see Silicon.par), so it can differ from the formula by a few tens of mV. Raising the doping 100 times on both sides adds \(2\times(kT/q)\ln 100\approx 0.24\) V, matching 0.95 − 0.71.

2. For Si 10¹⁶/10¹⁶ with \(V_{bi}\approx 0.71\) V: \(W(0)\approx 0.43\ \mu\)m, \(W(-5\ \text{V})\approx 1.22\ \mu\)m. The ratio \(1.22/0.43=2.83\approx\sqrt{5.71/0.71}\). The peak fields are about 3.3 × 10⁴ and 9.4 × 10⁴ V/cm. The depletion region still fits inside the two 2 µm layers, so the formula holds.

3. Without SRH: about 60 mV/decade (n ≈ 1) at both 0.2 V and 0.5 V. With SRH the slope is shallower at low bias. The crossover voltage, where recombination and diffusion currents are equal, is \(V_x=2(kT/q)\ln(J_{gr0}/J_0)\). An estimate with default lifetimes of order microseconds and short neutral regions (short diode, \(J_0\approx 4\times10^{-10}\) A/cm², \(J_{gr0}=qn_iW/2\tau\approx 7\times10^{-9}\) A/cm²) gives \(V_x\approx 0.15\) V; then n ≈ 1.2 at 0.2 V and ≈ 1.0 at 0.5 V. The shorter the lifetime, the higher \(V_x\) and the wider the n ≈ 2 range. The reverse current also rises by about \(J_{gr0}/J_0\) (around 20 times with these numbers).

4. A uniform n block has no space charge, so by Poisson the field is constant; \(n\) is constant too. Then a constant \(J_n=n\mu_n\,\mathrm{d}E_{Fn}/\mathrm{d}x\) means a constant \(\mathrm{d}E_{Fn}/\mathrm{d}x\), i.e. a straight \(E_{Fn}\); at the two ohmic contacts \(E_{Fn}=E_{Fp}\), so \(E_{Fp}\) is straight too. Current: \(\rho=1/(qn\mu_n)\approx 0.5\ \Omega\cdot\)cm (with \(\mu_n\approx 1200\) cm²/V·s), \(R=\rho L/A\approx 0.5\times4\times10^{-4}/10^{-8}=2\times10^{4}\ \Omega\) (cross-section 1 µm × 1 µm = 10⁻⁸ cm²), so \(I\approx 5\times10^{-5}\) A/µm at 1 V, linear in V.
