Xuất DXF, chuyển GDSII và đặt maskExport DXF, convert to GDSII and order

Chuẩn bị bản xuất, KLayout, thông tin đặt mask và bảng lỗi thường gặp.Preparing the export, KLayout conversion, ordering information and a table of common errors.

Bản vẽ chỉ có ích khi đến được máy ghi mask nguyên vẹn. Bài cuối hướng dẫn xuất DXF, chuyển sang GDSII bằng KLayout, kiểm tra, đặt mask và sửa các lỗi thường gặp.

1. Chuẩn bị bản để xuất

  1. Lưu bản gốc .dwg; làm việc trên một bản sao để xuất.
  2. Xóa hoặc tắt các layer không in (DIM, NOTE, và FRAME nếu nhà làm mask không cần).
  3. Nếu bộ chuyển đổi không hỗ trợ block: EXPLODE các block một lần (chỉ tách block, không tách tiếp polyline).
  4. Chạy lại danh sách kiểm tra: QSELECT polyline hở, OVERKILL, PURGE, AUDIT.

2. Xuất DXF

SAVEAS
  Files of type: AutoCAD 2000/LT2000 DXF (*.dxf)
  (hoặc AutoCAD R12/LT2 DXF nếu bộ chuyển đổi cũ yêu cầu)

Đặt tên file chứa đơn vị và phiên bản, ví dụ Ga2O3_SBD_v3_um.dxf.

3. Chuyển sang GDSII bằng KLayout

KLayout là phần mềm layout miễn phí, mã nguồn mở, được hầu hết phòng sạch khuyên dùng.

  1. File → Reader Options → DXF trước khi mở file:
    • Unit: đặt bằng kích thước một đơn vị bản vẽ tính theo µm (1 nếu bạn vẽ bằng µm, 1000 nếu bằng mm).
    • Chế độ polyline: chọn tạo đa giác từ polyline kín.
    • Số điểm trên mỗi đường tròn: đủ lớn (ví dụ 64) nếu bản vẽ có CIRCLE.
  2. File → Open file DXF. Kiểm tra ngay kích thước bằng thước đo (phím K): die phải đúng 2000 µm, không phải 2 µm hay 2 m.
  3. Các layer DXF xuất hiện theo tên. Gán số layer GDS cho từng layer (ví dụ OHMIC → 1/0, SCHOTTKY → 2/0) trong phần chỉnh sửa thuộc tính layer.
  4. File → Save As → định dạng GDS2.
  5. Mở lại file GDS vừa lưu và kiểm tra từng layer.

Tên menu có thể khác đôi chút giữa các phiên bản KLayout; hãy xem tài liệu của phiên bản bạn dùng. Một công cụ thương mại phổ biến khác là LinkCAD, thường do kỹ thuật viên phòng sạch vận hành; bạn chỉ cần báo đơn vị và layer.

4. Đặt mask

Thông tin cần ghi rõ cho nhà làm mask hoặc kỹ thuật viên phòng sạch:

MụcVí dụ

Kích thước tấm và vật liệu5 inch, soda-lime, Cr
Layer nào in trên tấm nàoGDS 1/0 → mask 1; GDS 2/0 → mask 2
Cực tính cho từng tấmMask 1: dark field (lift-off, cảm quang dương); mask 2: dark field

Luôn yêu cầu và kiểm tra kỹ bản thử PDF: vùng nào tối, vùng nào trong, các lỗ có đúng không, nhãn có đọc được không.

A drawing is only useful if it reaches the mask writer intact. This last lesson covers exporting DXF, converting to GDSII with KLayout, checking, ordering the mask and fixing common errors.

1. Prepare the export copy

  1. Save the original .dwg; work on a copy for export.
  2. Delete or turn off non-printing layers (DIM, NOTE, and FRAME if the mask shop does not need it).
  3. If the converter does not support blocks: EXPLODE the blocks once (break the blocks only, not the polylines inside).
  4. Rerun the checklist: QSELECT open polylines, OVERKILL, PURGE, AUDIT.

2. Export DXF

SAVEAS
  Files of type: AutoCAD 2000/LT2000 DXF (*.dxf)
  (or AutoCAD R12/LT2 DXF if an older converter requires it)

Put the unit and version in the file name, e.g. Ga2O3_SBD_v3_um.dxf.

3. Convert to GDSII with KLayout

KLayout is a free, open-source layout tool recommended by most cleanrooms.

  1. File → Reader Options → DXF before opening the file:
    • Unit: the size of one drawing unit in µm (1 if you drew in µm, 1000 if in mm).
    • Polyline mode: create polygons from closed polylines.
    • Points per full circle: large enough (e.g. 64) if the drawing contains CIRCLEs.
  2. File → Open the DXF. Immediately check dimensions with the ruler (key K): the die must be 2000 µm, not 2 µm or 2 m.
  3. DXF layers appear by name. Assign a GDS layer number to each (e.g. OHMIC → 1/0, SCHOTTKY → 2/0) in the layer properties editor.
  4. File → Save As → GDS2 format.
  5. Reopen the saved GDS and inspect each layer.

Menu names may differ slightly between KLayout versions; check the documentation of yours. Another common commercial tool is LinkCAD, often run by cleanroom staff; you only need to state units and layers.

4. Ordering the mask

Information to state clearly for the mask shop or cleanroom staff:

ItemExample
File format and unitsGDSII, 1 nm database unit, designed in µm
Plate size and material5 inch, soda-lime, Cr
Which layer on which plateGDS 1/0 → mask 1; GDS 2/0 → mask 2
Polarity per plateMask 1: dark field (lift-off, positive resist); mask 2: dark field
Reading orientationRight-reading from the chrome side, or mirrored
Critical dimension and toleranceCD 5 µm ± 0.5 µm

Always request and carefully check the PDF proof: which areas are dark, which clear, whether holes are right, whether labels read correctly.

5. Common errors and fixes

SymptomCauseFix
Design 1000× too big or smallDXF carries no units; wrong Unit when readingFix Unit in Reader Options; put the unit in the file name
Shapes missing on the maskOpen polylines, loose LINEs, HATCH, TEXTQSELECT Closed = No; PEDIT → Close; BOUNDARY
Fill inverted or holes goneNested shapes merged; wrong polarityUse a self-touching boundary or two layers; check the proof
Distorted shapes, odd resultsSelf-intersecting polylinesRedraw as non-crossing polygons
Circles become coarse polygonsArc precision too low on conversionUse 64-sided POLYGONs or raise points per circle
Objects far from the designStray objects drawn by mistakeZOOM Extents, delete strays
Distorted blocksBlocks inserted with x ≠ y scale, or external referencesInsert at 1:1, bind or explode xrefs
