PWM và analogWrite()PWM and analogWrite()

Chu kỳ nhiệm vụ, các chân PWM và tần số, làm LED sáng dần, giới hạn của PWM.Duty cycle, PWM pins and frequencies, fading an LED, the limits of PWM.

Chân số chỉ có 0 V và 5 V, vậy làm sao cho LED sáng mờ hay động cơ quay chậm? Câu trả lời là điều chế độ rộng xung (PWM): bật tắt rất nhanh và thay đổi tỉ lệ thời gian bật.

1. Ý tưởng của PWM

PWM tạo một sóng vuông với tần số cố định và thay đổi chu kỳ nhiệm vụ (duty cycle), tức phần trăm thời gian ở mức cao trong mỗi chu kỳ. Điện áp trung bình bằng \(D\times 5\) V. LED nhấp nháy nhanh hơn mắt nhìn được nên ta thấy độ sáng trung bình; động cơ có quán tính nên quay theo điện áp trung bình.

2. analogWrite()

analogWrite(chân, giá_trị) nhận giá trị 8 bit từ 0 đến 2⁸ − 1 = 255: 0 là luôn tắt, 255 là luôn bật, 127 là khoảng 50 %. Chỉ các chân có dấu ~ làm được: 3, 5, 6, 9, 10, 11 trên Uno. Tần số khoảng 490 Hz, riêng chân 5 và 6 khoảng 980 Hz.

Thử PWM

Hai cách làm LED sáng dần rồi tắt dần: dùng hai vòng for (cách trong bài giảng), hoặc tăng giảm một biến mỗi lần loop() chạy (ví dụ Fade chính thức).

FadeFor.inoChạy thử trên Wokwi ↗
// FadeFor.ino -- brighten then dim an LED with analogWrite() inside two for loops
const int LED = 9;                 // must be a PWM pin (~): 3, 5, 6, 9, 10 or 11 on the Uno

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  for (int i = 0; i <= 255; i++) {  // i++ is short for i = i + 1
    analogWrite(LED, i);            // duty cycle i/255
    delay(10);
  }
  for (int i = 255; i >= 0; i--) {  // i-- is short for i = i - 1
    analogWrite(LED, i);
    delay(10);
  }
}

Fade.inoChạy thử trên Wokwi ↗
/*
  Fade

  This example shows how to fade an LED on pin 9 using the analogWrite()
  function.

  The analogWrite() function uses PWM, so if you want to change the pin you're
  using, be sure to use another PWM capable pin. On most Arduino, the PWM pins
  are identified with a "~" sign, like ~3, ~5, ~6, ~9, ~10 and ~11.

  This example code is in the public domain.

  https://docs.arduino.cc/built-in-examples/basics/Fade/
*/

int led = 9;         // the PWM pin the LED is attached to
int brightness = 0;  // how bright the LED is
int fadeAmount = 5;  // how many points to fade the LED by

// the setup routine runs once when you press reset:
void setup() {
  // declare pin 9 to be an output:
  pinMode(led, OUTPUT);
}

// the loop routine runs over and over again forever:
void loop() {
  // set the brightness of pin 9:
  analogWrite(led, brightness);

  // change the brightness for next time through the loop:
  brightness = brightness + fadeAmount;

  // reverse the direction of the fading at the ends of the fade:
  if (brightness <= 0 || brightness >= 255) {
    fadeAmount = -fadeAmount;
  }
  // wait for 30 milliseconds to see the dimming effect
  delay(30);
}

Nguồn: Mã gốc của Arduino, phạm vi công cộng (CC0)

i++ là cách viết gọn của i = i + 1; tương tự i-- là i = i - 1.

3. PWM không phải là analog thật

Nhìn bằng dao động ký, chân PWM vẫn chỉ có 0 V và 5 V. Muốn có điện áp một chiều thật (ví dụ để cấp cho một mạch đo), cần thêm bộ lọc thông thấp RC với hằng số thời gian lớn hơn nhiều so với chu kỳ 2 ms, ví dụ 10 kΩ và 10 µF (τ = 0,1 s). Với LED và động cơ thì không cần lọc.

Độ sáng mắt cảm nhận không tỉ lệ tuyến tính với duty cycle: đi từ 0 lên 30 thấy thay đổi rõ, từ 200 lên 255 gần như không thấy. Muốn sáng dần "đều mắt" thì cho duty tăng theo hàm mũ thay vì tuyến tính.

4. Bài tập

  1. Tính điện áp trung bình và thời gian ở mức cao trong mỗi chu kỳ khi gọi analogWrite(9, 36).
  2. Vì sao analogWrite(13, 128) trên Uno không làm LED trên bo sáng một nửa?
  3. Viết sketch "nhịp thở": LED chân 9 sáng dần trong 1,5 s rồi tắt dần trong 1,5 s, lặp lại.
Đáp án và hướng dẫn

1. D = 36/255 = 14,1 %, điện áp trung bình 0,71 V. Chu kỳ ở 490 Hz là 2,04 ms, nên mức cao kéo dài khoảng 0,29 ms. (Đây là giá trị bài giảng dùng để chạy động cơ DC chậm.)

2. Chân 13 không nối với bộ định thời PWM. Với chân không PWM, analogWrite() chỉ cho ra LOW nếu giá trị dưới 128 và HIGH nếu từ 128 trở lên, nên LED sáng hẳn.

3. 256 bước trong 1500 ms là khoảng 6 ms mỗi bước:

void loop() {
  for (int i = 0; i <= 255; i++)  { analogWrite(9, i); delay(6); }
  for (int i = 255; i >= 0; i--)  { analogWrite(9, i); delay(6); }
}

Digital pins have only 0 V and 5 V, so how do you dim an LED or slow a motor? The answer is pulse-width modulation (PWM): switch very fast and vary the fraction of time the output is on.

1. The idea of PWM

PWM produces a square wave at a fixed frequency and varies the duty cycle, the percentage of each period spent high. The average voltage is \(D\times 5\) V. An LED flickers faster than the eye can see, so we perceive the average brightness; a motor has inertia, so it turns at the average voltage.

2. analogWrite()

analogWrite(pin, value) takes an 8-bit value from 0 to 2⁸ − 1 = 255: 0 is always off, 255 always on, 127 about 50 %. Only pins marked ~ can do it: 3, 5, 6, 9, 10, 11 on the Uno. The frequency is about 490 Hz, except about 980 Hz on pins 5 and 6.

Try PWM

Two ways to fade an LED up and down: two for loops (the lecture's version), or changing a variable a little on each pass through loop() (the official Fade example).

3. PWM is not true analog

On an oscilloscope a PWM pin still shows only 0 V and 5 V. To get a real DC voltage (for example to feed a measurement circuit) add an RC low-pass filter with a time constant much longer than the 2 ms period, e.g. 10 kΩ and 10 µF (τ = 0.1 s). LEDs and motors need no filter.

Perceived brightness is not linear in duty cycle: going from 0 to 30 is an obvious change, from 200 to 255 is barely visible. For a fade that looks even, raise the duty exponentially rather than linearly.

4. Exercises

  1. Compute the average voltage and the high time per period for analogWrite(9, 36).
  2. Why does analogWrite(13, 128) on the Uno not light the on-board LED at half brightness?
  3. Write a "breathing" sketch: the LED on pin 9 fades up over 1.5 s and down over 1.5 s, repeatedly.
Answers and hints

1. D = 36/255 = 14.1 %, an average of 0.71 V. The period at 490 Hz is 2.04 ms, so the high time is about 0.29 ms. (This is the value the lecture uses to run a DC motor slowly.)

2. Pin 13 is not connected to a PWM timer. On a non-PWM pin, analogWrite() outputs LOW for values below 128 and HIGH for 128 and above, so the LED is fully on.

3. 256 steps in 1500 ms is about 6 ms per step:

void loop() {
  for (int i = 0; i <= 255; i++)  { analogWrite(9, i); delay(6); }
  for (int i = 255; i >= 0; i--)  { analogWrite(9, i); delay(6); }
}
