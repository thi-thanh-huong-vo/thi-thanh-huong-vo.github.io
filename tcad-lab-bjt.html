Thực hành 5: transistor lưỡng cực npnLab 5: the npn bipolar transistor

Lớp chôn và sinker, mẹo boolean BAB, chuyển base sang chế độ dòng, họ IC–VCE và đồ thị Gummel.Buried layer and sinker, the BAB boolean trick, switching the base to current mode, IC–VCE family and Gummel plot.

Transistor lưỡng cực npn kiểu những năm 1970, với lớp chôn n⁺ và vùng sinker để đưa dòng collector lên bề mặt. Bài này giới thiệu hai kỹ thuật mới: chế độ boolean "BAB" khi dựng hình và chuyển điện cực sang chế độ dòng điện khi giải.

1. Cấu trúc

Kích thước theo bài giảng: rộng 2,2 µm; lớp epi dày 0,3 µm = Temit + Tbase + Tcol, gồm đảo transistor (x = 0,2–1,2 µm) và đảo sinker (1,5–2,0 µm), xen giữa là SiO₂; đế p dày 2,0 µm. Tiếp xúc base ở 0,3–0,7 µm, emitter 0,9–1,1 µm, collector 1,5–2,0 µm, đế ở cạnh dưới.

2. File SDE

;; bjt_dvs.cmd -- 1970s-style npn BJT with buried layer and sinker
;; x = 0..2.2 um, y = 0 at the epi top, growing downward
(sde:clear)
(sdegeo:set-default-boolean "BAB")   ; new regions do NOT overwrite existing ones

;; ---- SWB parameters ----
(define Temit  @Temit@)     ; emitter depth [um], e.g. 0.1
(define Tbase  @Tbase@)     ; base thickness [um], e.g. 0.1
(define Tcol   @Tcol@)      ; collector (epi below base) [um], e.g. 0.1
(define Ndepi  @Ndepi@)     ; epi = collector doping, e.g. 5e16
(define Nabase @Nabase@)    ; base peak, e.g. 3e18
(define Ndemit @Ndemit@)    ; emitter peak, e.g. 1e20
(define Tepi (+ Temit Tbase Tcol))     ; 0.3 um in the lecture
(define Hsub 2.0)  (define Wtot 2.2)

;; ---- geometry: silicon islands first, then oxide fills the gaps ----
(sdegeo:create-rectangle (position 0.2 0 0) (position 1.2 Tepi 0) "Silicon" "R.Epi")
(sdegeo:create-rectangle (position 1.5 0 0) (position 2.0 Tepi 0) "Silicon" "R.Sink")
(sdegeo:create-rectangle (position 0 Tepi 0) (position Wtot (+ Tepi Hsub) 0) "Silicon" "R.Sub")
(sdegeo:create-rectangle (position 0 0 0) (position Wtot Tepi 0) "SiO2" "R.Iso")  ; BAB: gaps only

;; ---- contacts ----
(for-each (lambda (x) (sdegeo:insert-vertex (position x 0 0))) (list 0.3 0.7 0.9 1.1))
(define (contact name x y)
  (sdegeo:define-contact-set name 4 (color:rgb 1 0 0) "##")
  (sdegeo:set-current-contact-set name)
  (sdegeo:define-2d-contact (find-edge-id (position x y 0)) name))
(contact "base_contact"      0.5  0)
(contact "emitter_contact"   1.0  0)
(contact "collector_contact" 1.75 0)
(contact "substrate_contact" 1.1  (+ Tepi Hsub))

;; ---- constant doping ----
(sdedr:define-constant-profile "C.Epi" "PhosphorusActiveConcentration" Ndepi)
(sdedr:define-constant-profile-region "Pl.Epi"  "C.Epi" "R.Epi")
(sdedr:define-constant-profile-region "Pl.Sink" "C.Epi" "R.Sink")
(sdedr:define-constant-profile "C.Sub" "BoronActiveConcentration" 1e16)
(sdedr:define-constant-profile-region "Pl.Sub" "C.Sub" "R.Sub")

;; ---- Gaussian implants; lateral diffusion ~20 nm ----
;; vertical sigma = Depth / sqrt(2 ln(Peak/ValueAtDepth)); Factor = 0.02 / sigma
(define (lat depth peak vad) (/ 0.02 (/ depth (sqrt (* 2 (log (/ peak vad)))))))
(define (gauss name species peak depth vad x0 x1 y)
  (sdedr:define-refeval-window (string-append "BL." name) "Line" (position x0 y 0) (position x1 y 0))
  (sdedr:define-gaussian-profile (string-append "G." name) species
     "PeakPos" 0 "PeakVal" peak "ValueAtDepth" vad "Depth" depth
     "Gauss" "Factor" (lat depth peak vad))
  (sdedr:define-analytical-profile-placement (string-append "P." name)
     (string-append "G." name) (string-append "BL." name) "Symm" "NoReplace" "Eval"))
;;     name    species                          peak    depth             value-at-depth      x0  x1  y
(gauss "base"  "BoronActiveConcentration"      Nabase  (+ Temit Tbase)   Ndepi               0.2 1.2 0)
(gauss "emit"  "PhosphorusActiveConcentration" Ndemit  Temit             (/ Nabase (exp 1))  0.9 1.1 0)
(gauss "sink"  "PhosphorusActiveConcentration" 5e19    (+ Tepi 0.2)      1e17                1.5 2.0 0)
(gauss "buri"  "PhosphorusActiveConcentration" 5e19    0.3               1e16                0.2 2.0 Tepi)

;; ---- mesh: follow the doping gradients ----
(sdedr:define-refinement-size "S.Si" 0.05 0.05 0.002 0.002)
(sdedr:define-refinement-function "S.Si" "DopingConcentration" "MaxTransDiff" 1)
(sdedr:define-refinement-material "Ref.Si" "S.Si" "Silicon")
(sde:build-mesh "snmesh" "-a -c boxmethod" "n@node@")

Mẹo "BAB". Ở chế độ mặc định "ABA", vùng tạo sau đè lên vùng tạo trước. Chế độ "BAB" thì ngược lại: vùng mới chỉ lấp phần còn trống. Nhờ vậy chỉ cần vẽ các đảo Si trước, rồi một hình chữ nhật SiO₂ phủ cả lớp epi; oxide tự lấp vào ba khe cách ly, không phải tính tọa độ từng khe.

Hàm Scheme tự viết. Hai hàm contact và gauss gói các lệnh lặp lại. Hàm lat đổi "khuếch tán ngang 20 nm" thành tham số Factor: với profile Gauss, độ lệch chuẩn theo chiều sâu là \(\sigma=\text{Depth}/\sqrt{2\ln(\text{PeakVal}/\text{ValueAtDepth})}\), còn Factor là tỉ lệ độ lan ngang trên \(\sigma\).

Vì sao emitter có giá trị tại độ sâu bằng NA,base/e? Để tiếp giáp emitter–base nằm gần đúng ở độ sâu Temit, nơi base Gauss đã giảm khỏi đỉnh. Mở n*_msh.tdr và cắt dọc tại x = 1,0 µm để kiểm tra vị trí hai tiếp giáp và độ dày base thực.

3. Giải trong cấu hình emitter chung

Đặc tuyến ra của BJT được vẽ theo dòng base cố định, không phải điện áp base. Nhưng quét thẳng dòng từ 0 rất khó hội tụ, vì dòng là hàm mũ của điện áp. Trình tự trong bài giảng:

  1. Giải cân bằng.
  2. Tăng điện áp base lên 0,5–0,6 V (ở chế độ điện áp, dễ hội tụ).
  3. Chuyển base_contact sang chế độ dòng.
  4. Tăng dòng base tới giá trị mục tiêu.
  5. Mở file .plt mới.
  6. Tăng điện áp collector tới giá trị mục tiêu.
* bjt_des.cmd -- common-emitter output characteristic IC-VCE at a fixed IB
Electrode {
  { Name = "emitter_contact"    Voltage = 0 }
  { Name = "base_contact"       Voltage = 0 }
  { Name = "collector_contact"  Voltage = 0 }
  { Name = "substrate_contact"  Voltage = 0 }
}
Physics {
  Mobility ( DopingDependence  HighFieldSaturation )
  EffectiveIntrinsicDensity ( OldSlotboom )        * band-gap narrowing (emitter!)
  Recombination ( SRH ( DopingDependence )  Auger )
}
Solve {
  * 1) equilibrium
  Coupled { Poisson }
  Coupled { Poisson Electron Hole }
  * 2) bring VBE close to turn-on in voltage mode (easy to converge)
  Quasistationary ( InitialStep = 0.05  MaxStep = 0.1  MinStep = 1e-5
    Goal { Name = "base_contact"  Voltage = 0.55 }
  ) { Coupled { Poisson Electron Hole } }
  * 3) switch the base to current mode: IB is now the boundary condition
  Set ( "base_contact"  mode current )
  * 4) ramp IB to the target (per um of depth in 2D)
  Quasistationary ( InitialStep = 0.1  Increment = 1.3  MaxStep = 0.2  MinStep = 1e-6
    Goal { Name = "base_contact"  Current = @Ib@ }
  ) { Coupled { Poisson Electron Hole } }
  * 5) new .plt file, then 6) ramp the collector
  NewCurrentPrefix = "icvce_"
  Quasistationary ( InitialStep = 0.01  Increment = 1.3  MaxStep = 0.05  MinStep = 1e-6
    Goal { Name = "collector_contact"  Voltage = @Vce_max@ }
  ) { Coupled { Poisson Electron Hole } }
}

Increment = 1.3 cho bước tăng tối đa 1,3 lần sau mỗi bước hội tụ, êm hơn mặc định. Quy ước dấu của dòng điện cực theo hướng dòng đi vào linh kiện; nếu sau bước 4 mà VBE tụt xuống âm, đổi dấu Current trong Goal. Lặp với một cây Ib (ví dụ 4 giá trị) để có họ đặc tuyến.

4. Đọc kết quả

  • Hệ số khuếch đại \(\beta=I_C/I_B\) đo ở vùng tích cực (VCE khoảng 2 V).
  • Vùng bão hòa ở VCE < khoảng 0,2 V: cả hai tiếp giáp đều phân cực thuận.
  • Hiệu ứng Early. VCE tăng làm vùng nghèo base–collector lấn vào base, base trung hòa mỏng đi, \(I_C\) tăng. Ngoại suy các đường về phía VCE âm, chúng gặp nhau gần \(-V_A\). Base mỏng hoặc pha tạp nhẹ thì VA nhỏ.
  • Đồ thị Gummel: VCE cố định, quét VBE ở chế độ điện áp, vẽ IC và IB trên thang log. β là khoảng cách giữa hai đường; β giảm ở dòng thấp (tái hợp trong vùng nghèo E–B) và ở dòng cao (bơm hạt dẫn mạnh, điện trở base).
* Gummel plot: VCE fixed, sweep VBE in voltage mode
Solve {
  Coupled { Poisson }  Coupled { Poisson Electron Hole }
  Quasistationary ( Goal { Name = "collector_contact"  Voltage = 2 } )
    { Coupled { Poisson Electron Hole } }
  NewCurrentPrefix = "gummel_"
  Quasistationary ( InitialStep = 0.01  MaxStep = 0.02  MinStep = 1e-6
    Goal { Name = "base_contact"  Voltage = 1.0 }
  ) { Coupled { Poisson Electron Hole } }
}

5. Bài tập

  1. Vẽ phân bố pha tạp dọc x = 1,0 µm; đo độ sâu các tiếp giáp E–B, B–C và độ dày base trung hòa.
  2. Thay đổi Tbase (0,05; 0,1; 0,15 µm) và vẽ β, VA theo Tbase.
  3. Thay đổi Nabase và giải thích vì sao β giảm khi base pha tạp nặng (hiệu suất phát xạ).
  4. Tắt EffectiveIntrinsicDensity(OldSlotboom) và so sánh β. Vì sao thu hẹp vùng cấm ở emitter quan trọng với BJT?
Đáp án và hướng dẫn

Các số dưới đây là tính tay theo mô hình giải tích để bạn có mốc đối chiếu. Kết quả mô phỏng sẽ lệch vài phần trăm đến vài chục phần trăm tùy giá trị \(n_i\), mô hình thu hẹp vùng cấm, lưới và cách trích; khi lệch, hãy giải thích được vì sao.

1. Tính từ chính các profile Gauss trong file SDE (với \(T_{emit}=T_{base}=T_{col}=0{,}1\ \mu\)m): tiếp giáp E–B ở khoảng 0,10 µm, nơi pha tạp base còn khoảng 1,05 × 10¹⁸ cm⁻³; tiếp giáp B–C ở đúng 0,20 µm vì ValueAtDepth của base bằng pha tạp epi. Base kim loại học dày khoảng 0,10 µm. Vùng nghèo E–B ở VBE ≈ 0 lấn vào base khoảng 0,03–0,035 µm, vùng nghèo B–C lấn vào base thêm khoảng 0,01 µm (phần lớn nằm ở phía epi nhẹ hơn), nên base trung hòa còn khoảng 0,05–0,06 µm. Lưu ý thêm: vùng nghèo B–C phía epi ở VCE = 2 V rộng khoảng 0,27 µm, lớn hơn \(T_{col}=0{,}1\ \mu\)m, nên collector epi bị nghèo hoàn toàn tới lớp chôn; cắt dọc x = 1,0 µm sẽ thấy điều này.

2. Base mỏng hơn: số Gummel của base \(Q_B/q=\int N_A\,dx\) nhỏ hơn, nên β tăng (gần tỉ lệ nghịch với \(W_B\) khi hiệu suất phát xạ chiếm ưu thế), nhưng \(V_A\approx Q_B/C_{BC}\) giảm, và với 0,05 µm có nguy cơ xuyên thủng base ở VCE vài volt. Base dày hơn cho chiều ngược lại. Do đó tích \(\beta V_A\) thay đổi ít hơn từng đại lượng riêng lẻ; đó là đánh đổi kinh điển khi thiết kế base.

3. Pha tạp base cao làm hiệu suất phát xạ giảm: \(\gamma\approx 1/\left(1+\dfrac{D_EN_BW_B}{D_BN_EW_E}\right)\), và \(\beta\approx (D_BN_EW_E)/(D_EN_BW_B)\) khi chỉ tính phun ngược lỗ trống vào emitter. Tăng \(N_B\) 2 lần làm β giảm khoảng 2 lần (thêm nữa do độ linh động electron trong base giảm). Bù lại, điện trở base nhỏ hơn và \(V_A\) lớn hơn.

4. Với mô hình Slotboom cũ, ở 10²⁰ cm⁻³ vùng cấm emitter hẹp đi khoảng \(\Delta E_g=9\text{ mV}\left[\ln\frac{N}{10^{17}}+\sqrt{\ln^2\frac{N}{10^{17}}+0{,}5}\right]\approx 0{,}125\) eV, làm \(n_{i,eff}^2\) trong emitter tăng khoảng \(e^{0{,}125/0{,}0259}\approx 125\) lần. Dòng lỗ trống phun ngược vào emitter tăng tương ứng, nên khi tắt mô hình này β sẽ lớn bất thực, có thể gấp hàng chục lần. Đây là lý do BJT Si cần BGN để mô phỏng đúng β, và vì sao HBT dùng emitter vùng cấm rộng (hay base SiGe).

A 1970s-style npn bipolar transistor, with an n⁺ buried layer and a sinker that brings the collector current back to the surface. This lab introduces two new techniques: the "BAB" boolean mode when building geometry, and switching an electrode to current mode when solving.

1. Structure

Dimensions from the lecture: 2.2 µm wide; a 0.3 µm epi layer = Temit + Tbase + Tcol, consisting of a transistor island (x = 0.2–1.2 µm) and a sinker island (1.5–2.0 µm) separated by SiO₂; a 2.0 µm p substrate. Base contact at 0.3–0.7 µm, emitter 0.9–1.1 µm, collector 1.5–2.0 µm, substrate on the bottom edge.

The "BAB" trick. In the default "ABA" mode a later region overwrites an earlier one. "BAB" is the reverse: a new region only fills what is still empty. So you draw the Si islands first, then one SiO₂ rectangle across the whole epi layer; the oxide fills the three isolation gaps by itself, with no need to work out each gap's coordinates.

Home-made Scheme functions. The contact and gauss functions wrap repeated commands. The lat function turns "20 nm lateral diffusion" into the Factor parameter: for a Gaussian the vertical standard deviation is \(\sigma=\text{Depth}/\sqrt{2\ln(\text{PeakVal}/\text{ValueAtDepth})}\), and Factor is the ratio of lateral spread to \(\sigma\).

Why is the emitter's value at depth NA,base/e? So that the emitter–base junction lands near depth Temit, where the base Gaussian has already dropped below its peak. Open n*_msh.tdr and cut vertically at x = 1.0 µm to check where both junctions are and how thick the base really is.

3. Solving in common-emitter configuration

A BJT's output characteristics are plotted at fixed base current, not base voltage. But ramping current directly from zero converges poorly, because current is exponential in voltage. The sequence from the lecture:

  1. Solve equilibrium.
  2. Raise the base voltage to 0.5–0.6 V (in voltage mode, which converges easily).
  3. Switch base_contact to current mode.
  4. Ramp the base current to the target.
  5. Open a new .plt file.
  6. Ramp the collector voltage to the target.
* bjt_des.cmd -- common-emitter output characteristic IC-VCE at a fixed IB
Electrode {
  { Name = "emitter_contact"    Voltage = 0 }
  { Name = "base_contact"       Voltage = 0 }
  { Name = "collector_contact"  Voltage = 0 }
  { Name = "substrate_contact"  Voltage = 0 }
}

  Coupled { Poisson }

  * 2) bring VBE close to turn-on in voltage mode (easy to converge)

    Goal { Name = "base_contact"  Voltage = 0.55 }
  ) { Coupled { Poisson Electron Hole } }
  * 3) switch the base to current mode: IB is now the boundary condition
  Set ( "base_contact"  mode current )
  * 4) ramp IB to the target (per um of depth in 2D)
  Quasistationary ( InitialStep = 0.1  Increment = 1.3  MaxStep = 0.2  MinStep = 1e-6
    Goal { Name = "base_contact"  Current = @Ib@ }
  ) { Coupled { Poisson Electron Hole } }
  * 5) new .plt file, then 6) ramp the collector
  NewCurrentPrefix = "icvce_"
  Quasistationary ( InitialStep = 0.01  Increment = 1.3  MaxStep = 0.05  MinStep = 1e-6
    Goal { Name = "collector_contact"  Voltage = @Vce_max@ }
  ) { Coupled { Poisson Electron Hole } }
}

Increment = 1.3 lets the step grow by at most 1.3 times after each converged step, gentler than the default. The sign convention takes electrode current as flowing into the device; if VBE goes negative after step 4, flip the sign of Current in the Goal. Repeat with a tree of Ib values (e.g. four) to get a family of curves.

4. Reading the results

  • Current gain \(\beta=I_C/I_B\), measured in the active region (VCE around 2 V).
  • Saturation region at VCE below about 0.2 V: both junctions are forward-biased.
  • Early effect. Higher VCE pushes the base–collector depletion region into the base, the neutral base narrows and \(I_C\) rises. Extrapolated back to negative VCE, the curves meet near \(-V_A\). A thin or lightly doped base gives a small VA.
  • Gummel plot: fixed VCE, sweep VBE in voltage mode, plot IC and IB on a log scale. β is the gap between the two curves; it falls at low current (recombination in the E–B depletion region) and at high current (high injection, base resistance).

5. Exercises

  1. Plot the doping along x = 1.0 µm; measure the E–B and B–C junction depths and the neutral base width.
  2. Vary Tbase (0.05, 0.1, 0.15 µm) and plot β and VA against Tbase.
  3. Vary Nabase and explain why β falls when the base is heavily doped (emitter efficiency).
  4. Turn off EffectiveIntrinsicDensity(OldSlotboom) and compare β. Why does band-gap narrowing in the emitter matter for a BJT?
Answers and hints

The numbers below are hand calculations from analytical models, given as reference points. Simulation results will differ by a few to a few tens of percent depending on the \(n_i\) value, band-gap narrowing, mesh and extraction method; when they differ, be able to say why.

1. Computed from the Gaussian profiles in the SDE file (with \(T_{emit}=T_{base}=T_{col}=0.1\ \mu\)m): the E–B junction is at about 0.10 µm, where the base doping is still about 1.05 × 10¹⁸ cm⁻³; the B–C junction is at exactly 0.20 µm because the base's ValueAtDepth equals the epi doping. The metallurgical base is about 0.10 µm thick. The E–B depletion region at VBE ≈ 0 takes about 0.03–0.035 µm of the base and the B–C one about another 0.01 µm (most of it lies on the lighter epi side), so the neutral base is about 0.05–0.06 µm. Note also: the B–C depletion on the epi side at VCE = 2 V is about 0.27 µm, more than \(T_{col}=0.1\ \mu\)m, so the epi collector is fully depleted down to the buried layer; the vertical cut at x = 1.0 µm shows it.

2. A thinner base has a smaller base Gummel number \(Q_B/q=\int N_A\,dx\), so β rises (roughly as \(1/W_B\) when emitter efficiency dominates), but \(V_A\approx Q_B/C_{BC}\) falls, and at 0.05 µm the base risks punching through at a few volts of VCE. A thicker base does the opposite. The product \(\beta V_A\) therefore changes less than either quantity alone; that is the classic base-design trade-off.

3. Higher base doping lowers the emitter efficiency: \(\gamma\approx 1/\left(1+\dfrac{D_EN_BW_B}{D_BN_EW_E}\right)\), and \(\beta\approx (D_BN_EW_E)/(D_EN_BW_B)\) when only hole back-injection into the emitter counts. Doubling \(N_B\) roughly halves β (a bit more, since electron mobility in the base also drops). In return, base resistance falls and \(V_A\) rises.

4. With the old Slotboom model, at 10²⁰ cm⁻³ the emitter gap narrows by about \(\Delta E_g=9\text{ mV}\left[\ln\frac{N}{10^{17}}+\sqrt{\ln^2\frac{N}{10^{17}}+0.5}\right]\approx 0.125\) eV, raising \(n_{i,eff}^2\) in the emitter about \(e^{0.125/0.0259}\approx 125\) times. Hole back-injection into the emitter rises accordingly, so with the model off β comes out unrealistically large, possibly tens of times too high. This is why Si BJTs need BGN to simulate β correctly, and why HBTs use a wide-gap emitter (or a SiGe base).
