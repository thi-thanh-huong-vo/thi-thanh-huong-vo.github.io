Tín hiệu analog và cảm biếnAnalog signals and sensors

ADC 10 bit, biến trở, map() và constrain(), cảm biến nhiệt TMP36 với đèn RGB, quang trở.The 10-bit ADC, potentiometers, map() and constrain(), a TMP36 with an RGB LED, photoresistors.

Thế giới thật là analog: nhiệt độ, ánh sáng, vị trí thay đổi liên tục. Bài này giải thích cách Arduino chuyển điện áp liên tục thành số bằng bộ chuyển đổi ADC, rồi đọc biến trở, cảm biến nhiệt TMP36 và quang trở.

1. Tín hiệu analog và số

Tín hiệu số chỉ có hai mức (0 và 5 V). Tín hiệu analog, như một sóng sin, nhận vô số giá trị giữa hai mức. Bộ chuyển đổi analog–số (ADC) chia khoảng điện áp thành \(2^N\) bậc với N là số bit. ADC 3 bit có 2³ = 8 mức (0–7); ADC của Uno có 10 bit, tức 1024 mức (0–1023), mỗi bậc 5 V/1024 ≈ 4,9 mV.

Điện áp vào → giá trị ADC

2. Đọc biến trở

Biến trở có ba chân: hai chân ngoài nối 5 V và GND, chân giữa (con trượt) nối A0. Xoay núm, điện áp ở A0 đi từ 0 đến 5 V.

  // initialize serial communication at 9600 bits per second:

}

// the loop routine runs over and over again forever:

  int sensorValue = analogRead(A0);
  // print out the value you read:

// the loop routine runs over and over again forever:
void loop() {
  // read the input on analog pin 0:
  int sensorValue = analogRead(A0);
  // Convert the analog reading (which goes from 0 - 1023) to a voltage (0 - 5V):
  float voltage = sensorValue * (5.0 / 1023.0);
  // print out the value you read:
  Serial.println(voltage);
}

3. Ánh xạ sang đầu ra: map() và constrain()

map(x, 0, 1023, 0, 255) đổi tỉ lệ một giá trị từ khoảng này sang khoảng khác (tính bằng số nguyên). constrain(x, a, b) giữ giá trị trong khoảng [a, b]. Ví dụ dưới dùng biến trở để chỉnh độ sáng LED:

AnalogInOutSerial.inoChạy thử trên Wokwi ↗
/*
  Analog input, analog output, serial output

  Reads an analog input pin, maps the result to a range from 0 to 255 and uses
  the result to set the pulse width modulation (PWM) of an output pin.
  Also prints the results to the Serial Monitor.

  The circuit:
  - potentiometer connected to analog pin 0.
    Center pin of the potentiometer goes to the analog pin.
    side pins of the potentiometer go to +5V and ground
  - LED connected from digital pin 9 to ground through 220 ohm resistor

  created 29 Dec. 2008
  modified 9 Apr 2012
  by Tom Igoe

  This example code is in the public domain.

  https://docs.arduino.cc/built-in-examples/analog/AnalogInOutSerial/
*/

// These constants won't change. They're used to give names to the pins used:
const int analogInPin = A0;  // Analog input pin that the potentiometer is attached to
const int analogOutPin = 9;  // Analog output pin that the LED is attached to

int sensorValue = 0;  // value read from the pot
int outputValue = 0;  // value output to the PWM (analog out)

void setup() {
  // initialize serial communications at 9600 bps:
  Serial.begin(9600);
}

void loop() {
  // read the analog in value:
  sensorValue = analogRead(analogInPin);
  // map it to the range of the analog out:
  outputValue = map(sensorValue, 0, 1023, 0, 255);
  // change the analog out value:
  analogWrite(analogOutPin, outputValue);

  // print the results to the Serial Monitor:
  Serial.print("sensor = ");
  Serial.print(sensorValue);
  Serial.print("\t output = ");
  Serial.println(outputValue);

  // wait 2 milliseconds before the next loop for the analog-to-digital
  // converter to settle after the last reading:
  delay(2);
}

4. Cảm biến đóng gói sẵn

  • Cảm biến khoảng cách hồng ngoại Sharp: dây đỏ 5 V, đen GND, trắng trả về điện áp 0–5 V theo khoảng cách (quan hệ không tuyến tính, cần bảng hiệu chỉnh).
  • Gia tốc kế ba trục analog: ba chân Xout, Yout, Zout cho điện áp theo độ nghiêng và chuyển động; điện thoại dùng cảm biến loại này để xoay màn hình.
  • TMP36: điện áp ra tuyến tính theo nhiệt độ, 10 mV/°C, bằng 0,5 V ở 0 °C (750 mV ở 25 °C). Kéo dài đường thẳng đó thì 0 V ứng với −50 °C và 1,75 V ứng với 125 °C.
$$T\,[^\circ\text{C}]=\left(V_{out}-0{,}5\right)\times 100$$

Hệ thống cảnh báo nhiệt độ của bài giảng: đèn RGB xanh lá khi nhiệt độ trong khoảng cho phép, đỏ khi quá nóng, xanh dương khi quá lạnh.

Tmp36Alert.inoChạy thử trên Wokwi ↗
// Tmp36Alert.ino -- TMP36 temperature sensor with an RGB status LED
// TMP36: +Vs -> 5 V, Vout -> A0, GND -> GND (flat side facing you: 5V, Vout, GND)
// Common-cathode RGB LED: R -> pin 9, G -> pin 10, B -> pin 11, each through 220 ohm
const int TEMP = A0;
const int RED = 9, GREEN = 10, BLUE = 11;
const float LOW_C = 18.0;          // below this: blue (too cold)
const float HIGH_C = 26.0;         // above this: red (too hot)

void setup() {
  Serial.begin(9600);
  pinMode(RED, OUTPUT);
  pinMode(GREEN, OUTPUT);
  pinMode(BLUE, OUTPUT);
}

void loop() {
  int raw = analogRead(TEMP);              // 0..1023
  float volts = raw * (5.0 / 1024.0);      // one ADC step = 5 V / 1024 = 4.9 mV
  float tempC = (volts - 0.5) * 100.0;     // TMP36: 0.5 V at 0 degC, +10 mV per degC

  Serial.print(tempC, 1);
  Serial.println(" C");

  digitalWrite(BLUE,  tempC < LOW_C);
  digitalWrite(GREEN, tempC >= LOW_C && tempC <= HIGH_C);
  digitalWrite(RED,   tempC > HIGH_C);
  delay(500);
}

5. Tự làm cảm biến: quang trở

Quang trở CdS có điện trở giảm khi được chiếu sáng (từ vài trăm kΩ trong tối xuống vài kΩ dưới đèn phòng, tùy loại). Ghép với một điện trở cố định thành cầu chia áp (Hình 2, phải) là có một cảm biến ánh sáng:

$$V_{A0}=5\ \text{V}\times\frac{R_{fix}}{R_{fix}+R_{LDR}}$$

LightMeter.inoChạy thử trên Wokwi ↗
// LightMeter.ino -- photoresistor voltage divider; the LED gets brighter as it gets darker
// Circuit: 5 V -> LDR -> A0 -> 10 kohm -> GND ; LED + 220 ohm on pin 9
const int LDR = A0;
const int LED = 9;

void setup() {
  Serial.begin(9600);
  pinMode(LED, OUTPUT);
}

void loop() {
  int light = analogRead(LDR);              // dark -> small value, bright -> large value
  int level = map(light, 0, 1023, 255, 0);  // invert: darker -> brighter LED
  level = constrain(level, 0, 255);         // keep the value inside 0..255
  analogWrite(LED, level);
  Serial.println(light);                    // try Tools > Serial Plotter
  delay(50);
}

Nguồn: Viết cho trang này dựa trên bài giảng, dùng tự do

Chọn \(R_{fix}\) xấp xỉ điện trở của quang trở ở mức sáng bạn quan tâm nhất thì độ nhạy ở đó lớn nhất. Cơ chế vật lý của quang trở (quang dẫn) được bàn kỹ ở bài Cảm biến ánh sáng.

6. Bài tập

  1. TMP36 cho analogRead() = 153. Nhiệt độ là bao nhiêu? Một bậc ADC tương ứng bao nhiêu °C?
  2. Quang trở có 20 kΩ trong bóng râm và 2 kΩ dưới đèn. Với \(R_{fix}\) = 10 kΩ, tính hai giá trị ADC.
  3. Vì sao không nên nối thẳng một chân analog vào điện áp lớn hơn 5 V (ví dụ pin 9 V qua cầu chia áp tính sai)?
Đáp án và hướng dẫn

1. V = 153 × 5/1024 = 0,747 V, T = (0,747 − 0,5) × 100 ≈ 24,7 °C. Một bậc ADC là 4,9 mV, tức khoảng 0,49 °C, nên số đọc nhảy theo bước gần nửa độ. (Muốn mịn hơn: lấy trung bình nhiều lần đọc, hoặc đổi điện áp tham chiếu sang 1,1 V nội bằng analogReference(INTERNAL), khi đó một bậc khoảng 0,11 °C nhưng chỉ đo được tới khoảng 60 °C.)

2. Bóng râm: V = 5 × 10/(10 + 20) = 1,67 V, ADC ≈ 341. Dưới đèn: V = 5 × 10/12 = 4,17 V, ADC ≈ 853.

3. Chân ADC có diode bảo vệ nối lên 5 V; điện áp vượt quá khoảng 5,5 V làm dòng chạy qua diode và có thể phá hỏng chân hoặc cả vi điều khiển. Luôn tính lại cầu chia áp để điện áp lớn nhất ở chân không quá 5 V.

The real world is analog: temperature, light and position change continuously. This lesson explains how the Arduino turns a continuous voltage into a number with its ADC, then reads a potentiometer, a TMP36 temperature sensor and a photoresistor.

1. Analog and digital signals

A digital signal has only two levels (0 and 5 V). An analog signal, like a sine wave, takes infinitely many values between them. An analog-to-digital converter (ADC) splits the voltage range into \(2^N\) steps, N being the number of bits. A 3-bit ADC has 2³ = 8 levels (0–7); the Uno's ADC has 10 bits, 1024 levels (0–1023), each step 5 V/1024 ≈ 4.9 mV.

Input voltage → ADC value

2. Reading a potentiometer

A potentiometer has three legs: the outer two go to 5 V and GND, the middle one (the wiper) to A0. Turning the knob sweeps the voltage at A0 from 0 to 5 V.

3. Mapping to an output: map() and constrain()

map(x, 0, 1023, 0, 255) rescales a value from one range to another (in integer arithmetic). constrain(x, a, b) keeps a value inside [a, b]. The example below uses the potentiometer to set LED brightness:

4. Packaged sensors

  • Sharp infrared distance sensor: red wire 5 V, black GND, white returns 0–5 V depending on distance (a non-linear relation that needs a calibration table).
  • Tri-axis analog accelerometer: Xout, Yout and Zout give voltages that follow tilt and motion; phones use this kind of sensor to rotate the screen.
  • TMP36: output voltage linear in temperature, 10 mV/°C, 0.5 V at 0 °C (750 mV at 25 °C). Extending the line, 0 V corresponds to −50 °C and 1.75 V to 125 °C.
$$T\,[^\circ\text{C}]=\left(V_{out}-0.5\right)\times 100$$

The lecture's temperature alert system: an RGB LED glows green when the temperature is in range, red when too hot, blue when too cold.

5. Build your own sensor: the photoresistor

A CdS photoresistor's resistance falls under light (from hundreds of kΩ in the dark to a few kΩ under room light, depending on the part). Combined with a fixed resistor in a divider (Figure 2, right) it becomes a light sensor:

$$V_{A0}=5\ \text{V}\times\frac{R_{fix}}{R_{fix}+R_{LDR}}$$

LightMeter.inoTry it on Wokwi ↗
// LightMeter.ino -- photoresistor voltage divider; the LED gets brighter as it gets darker
// Circuit: 5 V -> LDR -> A0 -> 10 kohm -> GND ; LED + 220 ohm on pin 9
const int LDR = A0;
const int LED = 9;

void setup() {
  Serial.begin(9600);
  pinMode(LED, OUTPUT);
}

void loop() {
  int light = analogRead(LDR);              // dark -> small value, bright -> large value
  int level = map(light, 0, 1023, 255, 0);  // invert: darker -> brighter LED
  level = constrain(level, 0, 255);         // keep the value inside 0..255
  analogWrite(LED, level);
  Serial.println(light);                    // try Tools > Serial Plotter
  delay(50);
}

Source: Written for this page from the lectures, free to use

Choosing \(R_{fix}\) close to the photoresistor's resistance at the light level you care about most gives the highest sensitivity there. The physics of the photoresistor (photoconductivity) is covered in the Light sensors lesson.

6. Exercises

  1. A TMP36 gives analogRead() = 153. What is the temperature? How many °C is one ADC step?
  2. A photoresistor is 20 kΩ in shade and 2 kΩ under a lamp. With \(R_{fix}\) = 10 kΩ, compute both ADC readings.
  3. Why should an analog pin never see more than 5 V (for example a 9 V battery through a miscalculated divider)?
Answers and hints

1. V = 153 × 5/1024 = 0.747 V, T = (0.747 − 0.5) × 100 ≈ 24.7 °C. One ADC step is 4.9 mV, about 0.49 °C, so readings jump in steps of nearly half a degree. (For finer readings, average several samples, or switch to the internal 1.1 V reference with analogReference(INTERNAL): one step is then about 0.11 °C, but the range ends near 60 °C.)

2. Shade: V = 5 × 10/(10 + 20) = 1.67 V, ADC ≈ 341. Under the lamp: V = 5 × 10/12 = 4.17 V, ADC ≈ 853.

3. The ADC pin has protection diodes to 5 V; above about 5.5 V current flows through the diode and can destroy the pin or the whole microcontroller. Always check the divider so the largest pin voltage stays at or below 5 V.
