Thực hành 4: MOSFET không lý tưởngLab 4: the non-ideal MOSFET

Điện tích oxide và C–V mixed mode, suy giảm độ linh động, DIBL và hiệu ứng thân.Oxide charge and mixed-mode C–V, mobility degradation, DIBL and the body effect.

MOSFET thật lệch khỏi mô hình lý tưởng vì bốn nguyên nhân chính được học trong môn này: điện tích trong oxide, suy giảm độ linh động, hiệu ứng kênh ngắn (DIBL) và hiệu ứng thân. Bài này cho thấy cách đưa từng hiệu ứng vào Sentaurus và cách đọc nó trên kết quả.

1. Điện tích bẫy trong oxide \(Q'_{ss}\)

Oxide luôn chứa điện tích dương cố định gần mặt phân cách Si/SiO₂. Mô hình hóa đơn giản nhất là gom toàn bộ thành một lớp điện tích \(Q'_{ss}\) (cm⁻²) đúng tại mặt phân cách. Trong SDevice, đó là một "bẫy" loại FixedCharge khai báo theo mặt phân cách giữa hai vùng (Sentaurus Device User Guide, chương Traps and Fixed Charges):

* fixed charge in the oxide, lumped at the Si/SiO2 interface
* region names come from SDE: "R.Sub" (silicon) and "R.Gox" (gate oxide)
Physics ( RegionInterface = "R.Sub/R.Gox" ) {
  Traps ( ( FixedCharge  Conc = @Qss@ ) )   * cm-2; positive value = positive charge
}

Dấu của Conc là dấu của điện tích. Ở mặt phân cách, đơn vị là cm⁻²; nếu khai báo theo vùng hay vật liệu thì là cm⁻³. Điện tích dương ở mặt phân cách hút electron về bề mặt, nên MOSFET kênh n mở sớm hơn:

$$V_T=\Phi_{ms}-\frac{qQ'_{ss}}{C_{ox}}+2\phi_F+\frac{|Q'_{d,max}|}{C_{ox}},\qquad \Delta V_T=-\frac{qQ'_{ss}}{C_{ox}}$$

Ví dụ tính tay (khác thông số bài tập để bạn tự làm bài tập): \(\phi_F=0{,}347\) V, \(C_{ox}=1{,}73\times10^{-7}\) F/cm², \(|Q'_{d,max}|/C_{ox}=0{,}278\) V, \(\Phi_{ms}\approx-0{,}91\) V, cho \(V_T\approx 0{,}07\) V khi \(Q'_{ss}=0\) và khoảng −0,86 V khi \(Q'_{ss}=10^{12}\) cm⁻². Giá trị \(\varepsilon_{ox}\) lấy trong SiO2.par của dự án để tính tay và mô phỏng dùng cùng một số.

Mô phỏng C–V

Điện dung cổng được tính bằng phân tích tín hiệu nhỏ trong chế độ hỗn hợp (mixed mode): linh kiện đặt trong khối System cùng các nguồn áp, ACCoupled chạy tại mỗi điểm DC.

* cv_des.cmd -- gate C-V of the MOSFET in mixed mode
Device MOS {
  Electrode {
    { Name = "source"    Voltage = 0 }   { Name = "drain"     Voltage = 0 }
    { Name = "gate"      Voltage = 0 }   { Name = "substrate" Voltage = 0 }
  }
  File { Grid = "@tdr@"  Parameter = "@parameter@"
         Plot = "n@node@_des.tdr"  Current = "n@node@_des.plt" }
  Physics { Mobility ( DopingDependence ) EffectiveIntrinsicDensity ( OldSlotboom ) }
  Physics ( RegionInterface = "R.Sub/R.Gox" ) { Traps ( ( FixedCharge Conc = @Qss@ ) ) }
}
File { Output = "n@node@_des.log"  ACExtract = "n@node@_ac" }

System {                                 * the device and four DC voltage sources
  MOS m1 ( source = s  drain = d  gate = g  substrate = b )
  Vsource_pset vs ( s 0 ) { dc = 0 }
  Vsource_pset vd ( d 0 ) { dc = 0 }
  Vsource_pset vg ( g 0 ) { dc = 0 }
  Vsource_pset vb ( b 0 ) { dc = 0 }
}
Math { Extrapolate  Derivatives  -RelErrControl  Digits = 5  Iterations = 20  Method = ParDiSo }

Solve {
  Coupled { Poisson }
  Coupled { Poisson Electron Hole }
  Quasistationary ( InitialStep = 0.02  MaxStep = 0.05  MinStep = 1e-5
    Goal { Parameter = vg.dc  Voltage = -3 }
  ) { Coupled { Poisson Electron Hole } }
  * sweep the gate up; at every DC point solve the small-signal AC problem at 1 MHz
  Quasistationary ( InitialStep = 0.005  MaxStep = 0.01  MinStep = 1e-5
    Goal { Parameter = vg.dc  Voltage = 3 }
  ) { ACCoupled ( StartFrequency = 1e6  EndFrequency = 1e6  NumberOfPoints = 1  Decade
                  Node ( s d g b )  Exclude ( vs vd vg vb ) )
      { Poisson Electron Hole } }
}

Điện dung cổng là cột c(g,g) trong file n*_ac_des.plt. Ba điều cần biết khi đọc đường C–V:

  • Với \(Q'_{ss}\) dương, cả đường C–V dịch sang trái một lượng \(qQ'_{ss}/C_{ox}\); từ độ dịch điện áp dải phẳng có thể suy ra \(Q'_{ss}\).
  • Vì nguồn và máng cung cấp electron, ở phía đảo điện dung quay về \(C_{ox}\) ngay cả ở 1 MHz. Muốn thấy đường C–V tần số cao "kinh điển" (đứng yên ở giá trị nhỏ nhất) thì mô phỏng tụ MOS không có nguồn, máng.
  • Cú pháp mixed mode thay đổi chút ít theo phiên bản; nếu báo lỗi, so với ví dụ C–V trong Sentaurus Training.

Giản đồ vùng qua cấu trúc MOS. Cắt theo phương y tại giữa kênh, ở VG = 0: khi \(Q'_{ss}\) tăng, vùng năng lượng ở bề mặt Si uốn xuống nhiều hơn (bề mặt tiến gần đến đảo), và điện trường trong oxide đổi độ lớn đúng bằng \(qQ'_{ss}/\varepsilon_{ox}\).

2. Suy giảm độ linh động

Bài giảng yêu cầu thêm một khối Physics riêng cho vật liệu Silicon, rồi lần lượt bật hai cơ chế:

* run 1: impurity scattering only (the "ideal" long-channel reference)
Physics ( Material = "Silicon" ) { Mobility ( DopingDependence ) }

* run 2: add surface scattering (Lombardi; the default Enormal model)
Physics ( Material = "Silicon" ) { Mobility ( DopingDependence  Enormal ) }

* run 3: add velocity saturation in the lateral field
Physics ( Material = "Silicon" ) { Mobility ( DopingDependence  Enormal  HighFieldSaturation ) }
  • Tán xạ bề mặt (Lombardi, Enormal). Điện trường vuông góc do cổng ép electron sát mặt phân cách, nơi tán xạ do phonon bề mặt và độ nhám bề mặt mạnh. Độ linh động giảm khi VG tăng, nên khoảng cách giữa các đường ID–VD ở VG cao co lại so với mô hình bình phương.
  • Bão hòa vận tốc (HighFieldSaturation). Electron trong Si đạt vận tốc bão hòa khoảng 10⁷ cm/s ở điện trường dọc lớn. Dòng bão hòa giảm, VDS,sat nhỏ hơn \(V_{GS}-V_T\), và với kênh ngắn \(I_{D,sat}\) tăng gần tuyến tính chứ không bình phương theo VGS.

Thí nghiệm gợi ý: VDS từ 0 đến 4 V, VGS = 0; 0,5; ...; 3 V, vẽ ba họ đường của ba lần chạy trên cùng thang đo.

3. Hiệu ứng kênh ngắn và DIBL

Ở kênh dài, vùng nghèo của tiếp giáp máng chỉ chiếm phần nhỏ của kênh, và rào năng lượng giữa nguồn và kênh do cổng quyết định hoàn toàn. Khi kênh ngắn lại cỡ vài lần độ dài đặc trưng \(\lambda\), điện thế của máng lan tới tận phía nguồn: rào bị hạ (Drain-Induced Barrier Lowering), electron dễ vượt rào hơn, nên VT giảm khi VDS tăng. DIBL được đo bằng \(\Delta V_T/\Delta V_{DS}\) (mV/V) và là nguyên nhân chính làm ID tiếp tục tăng theo VDS ở vùng bão hòa (độ dẫn ra hữu hạn).

Cách thấy DIBL trong mô phỏng: lấy hai thiết bị (ví dụ L = 10 µm và 0,7 µm), cùng VG dưới ngưỡng, cắt đường y = 1 nm từ nguồn sang máng ở VDS nhỏ và lớn, rồi vẽ ConductionBandEnergy. Với kênh dài, đỉnh rào không đổi; với kênh ngắn, đỉnh rào hạ xuống.

4. Hiệu ứng thân (phân cực đế)

Phân cực ngược đế (VBS < 0 với kênh n) làm vùng nghèo dưới kênh rộng ra, điện tích vùng nghèo tăng, nên cần VG lớn hơn để đảo:

$$\Delta V_T=\gamma\left(\sqrt{2\phi_F-V_{BS}}-\sqrt{2\phi_F}\right),\qquad \gamma=\frac{\sqrt{2\varepsilon_s qN_A}}{C_{ox}}$$

Với ví dụ ở mục 1, \(\gamma\approx 0{,}33\ \text{V}^{1/2}\) và VBS = −4 V làm VT tăng khoảng 0,44 V. Trình tự giải: đặt VD, đặt VBS, rồi quét VG.

Solve {
  Coupled { Poisson }
  Coupled { Poisson Electron Hole }
  Quasistationary ( InitialStep = 0.05  MaxStep = 0.2  MinStep = 1e-5
    Goal { Name = "drain"      Voltage = @Vd@ }     * e.g. 0.05 V, 1 V, 2 V
  ) { Coupled { Poisson Electron Hole } }
  Quasistationary ( InitialStep = 0.05  MaxStep = 0.2  MinStep = 1e-5
    Goal { Name = "substrate"  Voltage = @Vbs@ }    * 0, -1, -2, -4, -6 V
  ) { Coupled { Poisson Electron Hole } }
  NewCurrentPrefix = "idvg_"
  Quasistationary ( InitialStep = 0.01  MaxStep = 0.02  MinStep = 1e-5
    Goal { Name = "gate"  Voltage = 3 }
  ) { Coupled { Poisson Electron Hole } }
}

Vẽ VT theo \(\sqrt{|V_{BS}|}\): với kênh dài, đường gần thẳng với độ dốc xấp xỉ \(\gamma\). Với kênh ngắn, đường thấp hơn và dịch xuống thêm khi VDS lớn (DIBL); phân cực ngược đế làm vùng nghèo nguồn và máng tách xa nhau ra phía dưới và giảm bớt DIBL.

Góc nhìn Ga₂O₃

Với MOSFET và tụ MOS Ga₂O₃, điện tích cố định và bẫy mặt phân cách tại lớp Al₂O₃ hay SiO₂ trên Ga₂O₃ là đại lượng được trích từ C–V, giống hệt mục 1. Ví dụ, Zeng, Jia và Singisetti (2016) đo mật độ trạng thái mặt phân cách của tụ SiO₂/β-Ga₂O₃ (−201) lắng đọng ALD. Trong Sentaurus, cùng khối Physics(RegionInterface=...) được dùng, thêm bẫy mặt phân cách phân bố theo năng lượng bên cạnh FixedCharge.

  1. Với \(Q'_{ss}\) = 0; 10¹¹; 5 × 10¹¹; 10¹² cm⁻², mô phỏng C–V, ước lượng VT và điện áp dải phẳng từ đường cong, rồi so với công thức.
  2. Vẽ giản đồ vùng qua cấu trúc MOS ở VG = 0 cho bốn giá trị trên và giải thích sự thay đổi.
  3. Chạy ba mô hình độ linh động và so sánh họ đặc tuyến ID–VD. Mô hình nào ảnh hưởng nhiều nhất đến \(I_{D,sat}\)? Vì sao?
  4. Với L = 10; 1,5; 0,7 µm, vẽ VT theo \(\sqrt{|V_{BS}|}\) ở VDS nhỏ và lớn; giải thích bằng DIBL và hiệu ứng thân.

Real MOSFETs depart from the ideal model for four main reasons covered in this course: oxide charge, mobility degradation, short-channel effects (DIBL) and the body effect. This lab shows how to put each into Sentaurus and how to read it in the results.

1. Oxide trapped charge \(Q'_{ss}\)

An oxide always holds fixed positive charge near the Si/SiO₂ interface. The simplest model lumps it into a sheet \(Q'_{ss}\) (cm⁻²) right at the interface. In SDevice this is a FixedCharge "trap" declared on the interface between two regions (Sentaurus Device User Guide, chapter Traps and Fixed Charges):

* fixed charge in the oxide, lumped at the Si/SiO2 interface
* region names come from SDE: "R.Sub" (silicon) and "R.Gox" (gate oxide)
Physics ( RegionInterface = "R.Sub/R.Gox" ) {
  Traps ( ( FixedCharge  Conc = @Qss@ ) )   * cm-2; positive value = positive charge
}

The sign of Conc is the sign of the charge. At an interface the unit is cm⁻²; declared per region or material it is cm⁻³. Positive interface charge attracts electrons to the surface, so an n-channel MOSFET turns on earlier:

$$V_T=\Phi_{ms}-\frac{qQ'_{ss}}{C_{ox}}+2\phi_F+\frac{|Q'_{d,max}|}{C_{ox}},\qquad \Delta V_T=-\frac{qQ'_{ss}}{C_{ox}}$$

Hand calculation (with numbers different from the homework so you can still do it yourself): \(\phi_F=0.347\) V, \(C_{ox}=1.73\times10^{-7}\) F/cm², \(|Q'_{d,max}|/C_{ox}=0.278\) V, \(\Phi_{ms}\approx-0.91\) V, giving \(V_T\approx 0.07\) V at \(Q'_{ss}=0\) and about −0.86 V at \(Q'_{ss}=10^{12}\) cm⁻². Take \(\varepsilon_{ox}\) from the project's SiO2.par so the hand calculation and the simulation use the same number.

Simulating C–V

Gate capacitance is computed by small-signal analysis in mixed mode: the device sits in a System block with voltage sources, and ACCoupled runs at each DC point.

* cv_des.cmd -- gate C-V of the MOSFET in mixed mode
Device MOS {
  Electrode {
    { Name = "source"    Voltage = 0 }   { Name = "drain"     Voltage = 0 }
    { Name = "gate"      Voltage = 0 }   { Name = "substrate" Voltage = 0 }
  }

  Physics { Mobility ( DopingDependence ) EffectiveIntrinsicDensity ( OldSlotboom ) }
  Physics ( RegionInterface = "R.Sub/R.Gox" ) { Traps ( ( FixedCharge Conc = @Qss@ ) ) }
}

The gate capacitance is the c(g,g) column in n*_ac_des.plt. Three things to know when reading the C–V curve:

  • With positive \(Q'_{ss}\) the whole C–V curve shifts left by \(qQ'_{ss}/C_{ox}\); \(Q'_{ss}\) can be inferred from the flat-band voltage shift.
  • Because source and drain supply electrons, the capacitance returns to \(C_{ox}\) on the inversion side even at 1 MHz. To see the "textbook" high-frequency curve (which stays at its minimum), simulate a MOS capacitor without source and drain.
  • The mixed-mode syntax varies slightly between versions; if it errors, compare with the C–V example in Sentaurus Training.

Band diagram through the MOS stack. Cut along y at mid-channel at VG = 0: as \(Q'_{ss}\) grows, the bands at the Si surface bend down further (the surface moves toward inversion), and the oxide field changes by exactly \(qQ'_{ss}/\varepsilon_{ox}\).

2. Mobility degradation

The lecture asks for a separate Physics block for the Silicon material and then turns on the two mechanisms one at a time:

* run 1: impurity scattering only (the "ideal" long-channel reference)
Physics ( Material = "Silicon" ) { Mobility ( DopingDependence ) }

* run 2: add surface scattering (Lombardi; the default Enormal model)
Physics ( Material = "Silicon" ) { Mobility ( DopingDependence  Enormal ) }

* run 3: add velocity saturation in the lateral field
Physics ( Material = "Silicon" ) { Mobility ( DopingDependence  Enormal  HighFieldSaturation ) }
  • Surface scattering (Lombardi, Enormal). The gate's normal field presses electrons against the interface, where surface-phonon and surface-roughness scattering are strong. Mobility falls as VG rises, so the spacing between ID–VD curves at high VG shrinks compared with the square-law model.
  • Velocity saturation (HighFieldSaturation). Electrons in Si reach a saturation velocity of about 10⁷ cm/s at high lateral field. The saturation current drops, VDS,sat falls below \(V_{GS}-V_T\), and for short channels \(I_{D,sat}\) grows almost linearly rather than quadratically with VGS.

Suggested experiment: VDS from 0 to 4 V, VGS = 0, 0.5, ..., 3 V; plot the three families of curves from the three runs on the same axes.

3. Short-channel effects and DIBL

In a long channel the drain junction's depletion region takes up only a small part of the channel, and the source–channel barrier is set entirely by the gate. Once the channel is only a few characteristic lengths \(\lambda\) long, the drain potential reaches all the way to the source: the barrier is lowered (Drain-Induced Barrier Lowering), electrons cross it more easily, and VT drops as VDS rises. DIBL is measured as \(\Delta V_T/\Delta V_{DS}\) (mV/V) and is the main reason ID keeps rising with VDS in saturation (finite output conductance).

Seeing DIBL in simulation: take two devices (e.g. L = 10 µm and 0.7 µm) at the same subthreshold VG, cut along y = 1 nm from source to drain at small and large VDS, and plot ConductionBandEnergy. In the long channel the barrier peak stays put; in the short channel it drops.

4. The body effect (substrate bias)

Reverse-biasing the substrate (VBS < 0 for an n channel) widens the depletion region under the channel and raises the depletion charge, so a larger VG is needed to invert:

$$\Delta V_T=\gamma\left(\sqrt{2\phi_F-V_{BS}}-\sqrt{2\phi_F}\right),\qquad \gamma=\frac{\sqrt{2\varepsilon_s qN_A}}{C_{ox}}$$

For the example in section 1, \(\gamma\approx 0.33\ \text{V}^{1/2}\) and VBS = −4 V raises VT by about 0.44 V. Solve order: set VD, set VBS, then sweep VG.

Solve {
  Coupled { Poisson }
  Coupled { Poisson Electron Hole }
  Quasistationary ( InitialStep = 0.05  MaxStep = 0.2  MinStep = 1e-5
    Goal { Name = "drain"      Voltage = @Vd@ }     * e.g. 0.05 V, 1 V, 2 V
  ) { Coupled { Poisson Electron Hole } }
  Quasistationary ( InitialStep = 0.05  MaxStep = 0.2  MinStep = 1e-5
    Goal { Name = "substrate"  Voltage = @Vbs@ }    * 0, -1, -2, -4, -6 V
  ) { Coupled { Poisson Electron Hole } }
  NewCurrentPrefix = "idvg_"
  Quasistationary ( InitialStep = 0.01  MaxStep = 0.02  MinStep = 1e-5
    Goal { Name = "gate"  Voltage = 3 }
  ) { Coupled { Poisson Electron Hole } }
}

Plot VT against \(\sqrt{|V_{BS}|}\): for a long channel the line is nearly straight with slope close to \(\gamma\). For short channels it sits lower and drops further at large VDS (DIBL); reverse substrate bias pushes the source and drain depletion regions apart below the surface and reduces DIBL.

Ga₂O₃ perspective

For Ga₂O₃ MOSFETs and MOS capacitors, the fixed charge and interface traps at an Al₂O₃ or SiO₂ layer on Ga₂O₃ are extracted from C–V exactly as in section 1. For example, Zeng, Jia and Singisetti (2016) measured the interface state density of ALD SiO₂/β-Ga₂O₃ (−201) capacitors. In Sentaurus the same Physics(RegionInterface=...) block is used, with energy-distributed interface traps alongside the FixedCharge.
