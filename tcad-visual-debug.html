Sentaurus Visual và xử lý lỗi hội tụSentaurus Visual and fixing convergence

Vẽ và trích xuất bằng Tcl, danh sách xử lý khi không hội tụ và thói quen làm việc tốt.Plotting and extraction with Tcl, a convergence checklist and good working habits.

Bài cuối gồm hai kỹ năng mà người mới cần nhất: biến kết quả thành đồ thị và con số bằng Sentaurus Visual, và xử lý khi mô phỏng không hội tụ.

1. Sentaurus Visual

SVisual mở được cả file cấu trúc .tdr (xem phân bố 2D, cắt 1D) và file .plt (đồ thị I-V, C-V). Mọi thao tác chuột đều tương ứng với một lệnh Tcl, nên có thể tự động hóa bằng một tệp lệnh chạy trong SWB:

# svisual_vis.tcl -- plot the forward I-V and extract the current at 2 V
load_file n@node|sdevice@_des.plt -name IV
create_plot -1d -name Plot_IV
select_plots Plot_IV
create_curve -name Ianode -dataset IV \
    -axisX "anode OuterVoltage" -axisY "anode TotalCurrent"
set_axis_prop -plot Plot_IV -axis y -type log

# extraction: read the two columns and report the last current value
set V [get_variable_data "anode OuterVoltage" -dataset IV]
set I [get_variable_data "anode TotalCurrent" -dataset IV]
set Imax [lindex $I end]
puts "DOE: Imax $Imax"      ;# SWB shows this value in the project table

Dòng có dạng DOE: tên giá-trị được SWB đọc và hiển thị trong bảng dự án, giúp so sánh hàng loạt thí nghiệm mà không phải mở từng đồ thị.

Các thao tác hay dùng với file .tdr:

  • Hiển thị điện trường, mật độ electron, giản đồ vùng trên toàn cấu trúc.
  • Cắt 1D (cutline) dọc bề mặt hoặc theo chiều sâu dưới mép anode để vẽ điện trường hay giản đồ vùng.
  • Xuất dữ liệu ra file CSV để vẽ lại bằng Origin hay Python cho bài báo.

2. Khi mô phỏng không hội tụ

Thông báo thường gặp là bước Quasistationary bị chia nhỏ tới MinStep rồi dừng. Đi theo danh sách sau, từ dễ đến khó:

  1. Đọc file log từ lỗi đầu tiên: phương trình nào không hội tụ, ở bước nào, nút lưới nào có sai số lớn nhất.
  2. Kiểm tra cấu trúc: tên điện cực khớp giữa SDE và SDevice chưa; tiếp xúc có gán đúng cạnh không; vật liệu có tham số chưa (cảnh báo "undefined model" hay "parameter not found").
  3. Nghiệm ban đầu: giải Poisson riêng trước với nhiều vòng lặp; sau đó mới thêm phương trình hạt tải.
  4. Giảm bước: InitialStep và MaxStep nhỏ hơn, đặc biệt gần đánh thủng hay khi bẫy bắt đầu nạp.
  5. Bớt phương trình: với Ga₂O₃, bỏ Hole khi không cần.
  6. Độ chính xác số: bật độ chính xác mở rộng cho vật liệu vùng cấm siêu rộng; tăng Iterations.
  7. Lưới: lưới quá thô ở mép điện cực, hoặc thay đổi kích thước ô quá đột ngột, đều gây khó hội tụ; làm mịn và làm mượt chuyển tiếp.
  8. Bật mô hình từng cái một: nếu bật đồng thời ion hóa, bẫy, xuyên hầm và nhiệt mà không hội tụ, hãy tắt hết rồi bật lại từng mô hình để tìm thủ phạm.

3. Thói quen làm việc tốt

  • Bắt đầu đơn giản: cấu trúc 1D hoặc 2D thô, mô hình tối thiểu; chỉ thêm khi cần giải thích dữ liệu.
  • Luôn so sánh với một kết quả biết trước (ví dụ phương trình phát xạ nhiệt điện tử giải tích) trước khi tin mô phỏng phức tạp hơn.
  • Thử nghiệm hội tụ lưới cho mọi kết quả sẽ công bố.
  • Lưu bảng các mô hình, tham số và nguồn trích dẫn; phần "Simulation details" của bài báo sẽ cần đúng những thông tin này.

The last lesson covers the two skills beginners need most: turning results into plots and numbers with Sentaurus Visual, and dealing with simulations that do not converge.

1. Sentaurus Visual

SVisual opens both structure files (.tdr, for 2D distributions and 1D cuts) and current files (.plt, for I-V and C-V plots). Every mouse action corresponds to a Tcl command, so you can automate it with a command file run inside SWB:

# svisual_vis.tcl -- plot the forward I-V and extract the current at 2 V
load_file n@node|sdevice@_des.plt -name IV
create_plot -1d -name Plot_IV
select_plots Plot_IV
create_curve -name Ianode -dataset IV \
    -axisX "anode OuterVoltage" -axisY "anode TotalCurrent"
set_axis_prop -plot Plot_IV -axis y -type log

# extraction: read the two columns and report the last current value
set V [get_variable_data "anode OuterVoltage" -dataset IV]
set I [get_variable_data "anode TotalCurrent" -dataset IV]
set Imax [lindex $I end]
puts "DOE: Imax $Imax"      ;# SWB shows this value in the project table

A line of the form DOE: name value is read by SWB and shown in the project table, so you can compare many experiments without opening each plot.

Common operations on .tdr files:

  • Show the field, electron density or band diagram over the whole structure.
  • 1D cutlines along the surface or vertically under the anode edge to plot field or band diagrams.
  • Export data as CSV to replot in Origin or Python for papers.

2. When the simulation does not converge

The usual message is that the Quasistationary step was reduced to MinStep and the run stopped. Work through this list, from easy to hard:

  1. Read the log from the first error: which equation failed, at which step, which mesh node had the largest error.
  2. Check the structure: electrode names match between SDE and SDevice; contacts are on the right edges; materials have parameters (warnings such as "undefined model" or "parameter not found").
  3. Initial solution: solve Poisson alone first with many iterations; only then add carrier equations.
  4. Smaller steps: reduce InitialStep and MaxStep, especially near breakdown or when traps start to charge.
  5. Fewer equations: for Ga₂O₃, drop Hole when not needed.
  6. Numerical precision: enable extended precision for ultra-wide bandgap materials; raise Iterations.
  7. Mesh: a mesh too coarse at electrode edges, or cell sizes changing too abruptly, both hurt convergence; refine and smooth the transitions.
  8. Enable models one at a time: if impact ionization, traps, tunneling and thermal models are all on and nothing converges, turn them all off and re-enable one by one to find the culprit.

3. Good working habits

  • Start simple: a 1D or coarse 2D structure, minimal models; add only what is needed to explain data.
  • Always compare with a known result (e.g. the analytical thermionic emission equation) before trusting a more complex simulation.
  • Run a mesh convergence test for every result you will publish.
  • Keep a table of models, parameters and their sources; the "Simulation details" section of a paper needs exactly this.

4. Where to learn more

  • Sentaurus Training, shipped with the software: complete examples for diodes, MOSFETs, power devices and C-V.
  • University guides: UC Berkeley's materials, CMC Microsystems courses, D. W. Parent's student guide.
  • Books: Selberherr (numerical foundations), Vasileska–Goodnick–Klimeck (modeling), Sarkar (TCAD for MOSFETs).
  • Ga₂O₃ papers with detailed simulation sections: read the model setup carefully to learn how others choose parameters.
