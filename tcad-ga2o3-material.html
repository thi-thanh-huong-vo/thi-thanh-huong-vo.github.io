Tham số vật liệu Ga₂O₃ và hiệu chỉnhGa₂O₃ material parameters and calibration

Tệp tham số, giá trị khởi đầu có nguồn, quy trình hiệu chỉnh và khai báo bẫy sâu.Parameter files, sourced starting values, a calibration sequence and declaring deep traps.

Với Si, Sentaurus có sẵn bộ tham số đã hiệu chỉnh kỹ. Với Ga₂O₃, bạn thường phải tự xây dựng tệp tham số từ tài liệu đã công bố, rồi hiệu chỉnh theo dữ liệu đo. Bài này giới thiệu cách làm và các giá trị khởi đầu hợp lý.

1. Tệp tham số hoạt động thế nào

Mỗi vật liệu có một tệp .par gồm nhiều khối, mỗi khối ứng với một mô hình (hằng số điện môi, vùng cấm, mật độ trạng thái, độ linh động, ion hóa va chạm...). SDevice đọc tệp này qua dòng Parameter = "..." trong khối File, hoặc theo từng vật liệu trong các khối Material = "..." của tệp tham số tổng.

Cách an toàn nhất để có đúng cú pháp: in ra tệp tham số mặc định của một vật liệu có sẵn rồi sửa giá trị:

sdevice -P:GaN  >  Ga2O3.par      # in tham số mặc định của GaN
# sửa các giá trị trong Ga2O3.par cho Ga₂O₃

2. Đoạn tệp tham số minh họa

* Ga2O3.par -- ILLUSTRATIVE excerpt, check every keyword against
* the default file printed by:  sdevice -P:GaN  (or another material)

Epsilon {
  epsilon = 10.0                 * relative permittivity
}
Bandgap {
  Chi0 = 4.0                     * electron affinity (eV)
  Eg0  = 4.8                     * bandgap at 0 K reference (eV)
  alpha = 0.0   beta = 0.0       * no temperature dependence at first
}
eDOSMass {
  Formula = 2
  Nc300 = 3.7e18                 * effective density of states (cm^-3)
}
ConstantMobility {
  mumax = 200 , 50               * electrons , holes (cm^2/Vs)
}
HighFieldDependence {
  vsat0 = 2.0e7 , 1.0e7          * saturation velocity (cm/s)
}

Đây chỉ là đoạn minh họa cấu trúc: tên khối và tên tham số phải khớp với tệp mặc định của phiên bản bạn dùng.

4. Quy trình hiệu chỉnh

  1. C-V trước: khớp đường \(1/C^2\) theo điện áp để xác định nồng độ pha tạp lớp trôi và điện thế tiếp xúc.
  2. I-V thuận ở dòng thấp: khớp chiều cao rào \(\Phi_B\) và hệ số lý tưởng.
  3. I-V thuận ở dòng cao: khớp độ linh động và điện trở nối tiếp (gồm đế và tiếp xúc ohmic).
  4. Theo nhiệt độ: bật sự phụ thuộc nhiệt độ của độ linh động và vùng cấm; nếu xu hướng không khớp, xét đến bẫy.
  5. Dòng rò ngược và đánh thủng sau cùng, vì cần nhiều mô hình phức tạp nhất.

5. Thêm bẫy sâu

Ga₂O₃ có các mức bẫy sâu điển hình được ký hiệu E1–E4 trong các phép đo DLTS; E2 (khoảng 0,75–0,8 eV dưới vùng dẫn) thường gắn với Fe, E3 (khoảng 1,0 eV) gắn với các khuyết tật nội tại. Khai báo bẫy theo vật liệu:

Physics ( Material = "Ga2O3" ) {
  Traps (
    ( Acceptor Level fromCondBand EnergyMid = 0.75
      Conc = 1e15  eXsection = 1e-15  hXsection = 1e-15 )   * E2-like level
    ( Acceptor Level fromCondBand EnergyMid = 1.0
      Conc = 5e14  eXsection = 1e-15  hXsection = 1e-15 )   * E3-like level
  )
}

Nồng độ và tiết diện bắt ở đây chỉ là giá trị minh họa; hãy dùng giá trị từ DLTS hoặc từ chính phép đo của bạn.

Góc nhìn Ga₂O₃

Khi khớp C-V theo nhiệt độ của diode Schottky Ga₂O₃, điện dung ở nhiệt độ cao thay đổi theo tần số mà mô hình không bẫy không giải thích được. Đưa vào một mức bẫy acceptor sâu với hằng số thời gian phát xạ phụ thuộc nhiệt độ là bước giúp mô phỏng khớp với thực nghiệm.

For Si, Sentaurus ships with carefully calibrated parameters. For Ga₂O₃ you usually build the parameter file yourself from published data and then calibrate it against measurements. This lesson shows how, with reasonable starting values.

1. How parameter files work

Each material has a .par file made of blocks, one per model (permittivity, bandgap, density of states, mobility, impact ionization...). SDevice reads it via the Parameter = "..." line in the File section, or per material via Material = "..." blocks in a global parameter file.

The safest way to get the syntax right: print the default parameter file of an existing material and edit the values:

sdevice -P:GaN  >  Ga2O3.par      # print GaN default parameters
# edit the values in Ga2O3.par for Ga₂O₃

2. An illustrative parameter excerpt

* Ga2O3.par -- ILLUSTRATIVE excerpt, check every keyword against
* the default file printed by:  sdevice -P:GaN  (or another material)

Bandgap {

  Eg0  = 4.8                     * bandgap at 0 K reference (eV)

4. A calibration sequence

  1. C-V first: fit \(1/C^2\) versus voltage for the drift-layer doping and built-in potential.
  2. Low-current forward I-V: fit barrier height \(\Phi_B\) and ideality factor.
  3. High-current forward I-V: fit mobility and series resistance (substrate and ohmic contact).
  4. Versus temperature: switch on temperature-dependent mobility and bandgap; if the trend does not match, consider traps.
  5. Reverse leakage and breakdown last, since they need the most complex models.

5. Adding deep traps

Ga₂O₃ has typical deep levels labeled E1–E4 in DLTS; E2 (about 0.75–0.8 eV below the conduction band) is usually linked to Fe, E3 (about 1.0 eV) to native defects. Declare traps per material:

Physics ( Material = "Ga2O3" ) {
  Traps (
    ( Acceptor Level fromCondBand EnergyMid = 0.75
      Conc = 1e15  eXsection = 1e-15  hXsection = 1e-15 )   * E2-like level
    ( Acceptor Level fromCondBand EnergyMid = 1.0
      Conc = 5e14  eXsection = 1e-15  hXsection = 1e-15 )   * E3-like level
  )
}

The concentrations and cross sections here are illustrative only; use values from DLTS or from your own measurements.

Ga₂O₃ perspective

When fitting the temperature-dependent C-V of Ga₂O₃ Schottky diodes, the high-temperature capacitance varies with frequency in a way a trap-free model cannot explain. Adding a deep acceptor level with a temperature-dependent emission time constant is the step that brings simulation and experiment together.
