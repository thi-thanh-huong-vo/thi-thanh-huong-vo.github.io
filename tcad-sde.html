Dựng cấu trúc với Structure EditorBuilding structures with Structure Editor

File lệnh Scheme hoàn chỉnh cho diode Schottky Ga₂O₃: vùng, tiếp xúc, pha tạp và lưới.A complete Scheme file for a Ga₂O₃ Schottky diode: regions, contacts, doping and mesh.

Sentaurus Structure Editor (SDE) dựng cấu trúc linh kiện: vùng vật liệu, tiếp xúc, pha tạp và lưới. File lệnh viết bằng Scheme, một ngôn ngữ dạng Lisp với rất nhiều dấu ngoặc. Bài này dựng cấu trúc một nửa của diode Schottky Ga₂O₃ thẳng đứng.

1. Cấu trúc cần dựng

Linh kiện đối xứng, nên chỉ mô phỏng một nửa với biên trái là trục đối xứng. Đơn vị độ dài trong SDE mặc định là µm.

2. File lệnh hoàn chỉnh

; ---- Ga2O3 Schottky barrier diode, half structure (units: um) ----
(sde:clear)
(define W  50.0)        ; half width of the simulated device
(define Ra @Ra@)        ; anode half width, taken from an SWB parameter
(define Td 10.0)        ; drift layer thickness
(define Ts 2.0)         ; simulated part of the n+ substrate

; 1. Regions: material name and region name
(sdegeo:create-rectangle (position 0 0 0)  (position W Td 0)        "Ga2O3" "R.Drift")
(sdegeo:create-rectangle (position 0 Td 0) (position W (+ Td Ts) 0) "Ga2O3" "R.Sub")

; 2. Contacts: split the top edge at the anode edge, then assign edges
(sdegeo:insert-vertex (position Ra 0 0))
(sdegeo:define-contact-set "anode"   4 (color:rgb 1 0 0) "##")
(sdegeo:define-contact-set "cathode" 4 (color:rgb 0 0 1) "##")
(sdegeo:define-2d-contact (find-edge-id (position (/ Ra 2) 0 0)) "anode")
(sdegeo:define-2d-contact (find-edge-id (position (/ W 2) (+ Td Ts) 0)) "cathode")

; 3. Doping: constant n-type profiles in each region
(sdedr:define-constant-profile "P.Drift" "NDopantActiveConcentration" @Nd@)
(sdedr:define-constant-profile-region "PL.Drift" "P.Drift" "R.Drift")
(sdedr:define-constant-profile "P.Sub" "NDopantActiveConcentration" 5e18)
(sdedr:define-constant-profile-region "PL.Sub" "P.Sub" "R.Sub")

; 4. Mesh: coarse everywhere, fine near the anode edge
(sdedr:define-refinement-size "RS.Global" 2.0 1.0 0.5 0.2)
(sdedr:define-refinement-region "RP.Global" "RS.Global" "R.Drift")
(sdedr:define-refeval-window "Win.Edge" "Rectangle" (position (- Ra 2) 0 0) (position (+ Ra 2) 1 0))
(sdedr:define-refinement-size "RS.Edge" 0.1 0.05 0.01 0.005)
(sdedr:define-refinement-placement "RP.Edge" "RS.Edge" "Win.Edge")

; 5. Build the mesh and save n<node>_msh.tdr
(sde:build-mesh "snmesh" "" "n@node@_msh")

3. Giải thích từng phần

  • Cú pháp Scheme: mỗi lệnh nằm trong ngoặc, tên lệnh đứng đầu: (lệnh đối-số-1 đối-số-2 ...). Phép tính cũng vậy: (+ Td Ts) là Td + Ts. Dòng bắt đầu bằng ; là chú thích.
  • Vùng: sdegeo:create-rectangle nhận hai góc, tên vật liệu và tên vùng. Tên vùng dùng để gán pha tạp, lưới và mô hình vật lý riêng cho từng vùng.
  • Vật liệu Ga₂O₃: tùy phiên bản Sentaurus, Ga₂O₃ có thể chưa có trong cơ sở dữ liệu vật liệu. Khi đó cần khai báo vật liệu mới (tệp datexcodes.txt trong thư mục dự án) và cung cấp tệp tham số riêng (xem bài tham số vật liệu).
  • Tiếp xúc: tách cạnh trên tại mép anode bằng insert-vertex, rồi gán cạnh bên trái cho anode và cạnh đáy cho cathode. Tên tiếp xúc phải khớp với phần Electrode trong SDevice.
  • Pha tạp: NDopantActiveConcentration là loại donor chung, phù hợp khi không cần phân biệt Si hay Sn. Profile Gauss hoặc từ file đo SIMS cũng có thể được dùng.
  • Lưới: bốn số của define-refinement-size là kích thước ô lớn nhất theo x, y và nhỏ nhất theo x, y. Cửa sổ Win.Edge làm mịn lưới quanh mép anode, nơi điện trường cực đại khi phân cực ngược.
  • Tham số SWB: @Ra@ và @Nd@ được thay bằng giá trị của từng thí nghiệm, nên một file lệnh tạo được cả loạt cấu trúc.

4. Kiểm tra cấu trúc

  1. Mở file n*_msh.tdr trong SVisual; kiểm tra vùng, tiếp xúc (tô màu) và pha tạp.
  2. Xem lưới: đủ mịn ở mép anode và bề mặt chưa? Số nút có hợp lý không (vài nghìn đến vài chục nghìn cho 2D)?
  3. Có thể chạy SDE ở chế độ đồ họa để vẽ tương tác; mọi thao tác chuột được ghi lại thành lệnh Scheme trong cửa sổ lệnh, rất hữu ích để học cú pháp.

5. Mở rộng

  • Field plate: thêm vùng điện môi (ví dụ "SiO2") trên bề mặt ngoài anode, và kéo dài kim loại anode lên trên điện môi.
  • Vành bảo vệ hay vùng cấy N: thêm vùng có điện trở cao hoặc pha tạp bù quanh mép anode.
  • Cấu trúc tròn: dùng chế độ đối xứng trụ trong SDevice để mô phỏng anode tròn bằng cấu trúc 2D.

Sentaurus Structure Editor (SDE) builds the device structure: material regions, contacts, doping and mesh. Command files are written in Scheme, a Lisp-like language with lots of parentheses. This lesson builds the half structure of a vertical Ga₂O₃ Schottky diode.

1. The structure to build

The device is symmetric, so only half is simulated, with the left edge as the symmetry axis. SDE's default length unit is µm.

2. The complete command file

; ---- Ga2O3 Schottky barrier diode, half structure (units: um) ----
(sde:clear)
(define W  50.0)        ; half width of the simulated device
(define Ra @Ra@)        ; anode half width, taken from an SWB parameter
(define Td 10.0)        ; drift layer thickness
(define Ts 2.0)         ; simulated part of the n+ substrate

; 1. Regions: material name and region name
(sdegeo:create-rectangle (position 0 0 0)  (position W Td 0)        "Ga2O3" "R.Drift")
(sdegeo:create-rectangle (position 0 Td 0) (position W (+ Td Ts) 0) "Ga2O3" "R.Sub")

; 2. Contacts: split the top edge at the anode edge, then assign edges
(sdegeo:insert-vertex (position Ra 0 0))
(sdegeo:define-contact-set "anode"   4 (color:rgb 1 0 0) "##")
(sdegeo:define-contact-set "cathode" 4 (color:rgb 0 0 1) "##")
(sdegeo:define-2d-contact (find-edge-id (position (/ Ra 2) 0 0)) "anode")
(sdegeo:define-2d-contact (find-edge-id (position (/ W 2) (+ Td Ts) 0)) "cathode")

; 3. Doping: constant n-type profiles in each region
(sdedr:define-constant-profile "P.Drift" "NDopantActiveConcentration" @Nd@)
(sdedr:define-constant-profile-region "PL.Drift" "P.Drift" "R.Drift")
(sdedr:define-constant-profile "P.Sub" "NDopantActiveConcentration" 5e18)
(sdedr:define-constant-profile-region "PL.Sub" "P.Sub" "R.Sub")

; 4. Mesh: coarse everywhere, fine near the anode edge
(sdedr:define-refinement-size "RS.Global" 2.0 1.0 0.5 0.2)
(sdedr:define-refinement-region "RP.Global" "RS.Global" "R.Drift")
(sdedr:define-refeval-window "Win.Edge" "Rectangle" (position (- Ra 2) 0 0) (position (+ Ra 2) 1 0))
(sdedr:define-refinement-size "RS.Edge" 0.1 0.05 0.01 0.005)
(sdedr:define-refinement-placement "RP.Edge" "RS.Edge" "Win.Edge")

; 5. Build the mesh and save n<node>_msh.tdr
(sde:build-mesh "snmesh" "" "n@node@_msh")

3. Section by section

  • Scheme syntax: each command sits in parentheses with the command name first: (command arg-1 arg-2 ...). Arithmetic too: (+ Td Ts) is Td + Ts. Lines starting with ; are comments.
  • Regions: sdegeo:create-rectangle takes two corners, a material name and a region name. Region names are used to assign doping, mesh and region-specific physics.
  • The Ga₂O₃ material: depending on your Sentaurus version, Ga₂O₃ may not be in the material database. You then declare a new material (a datexcodes.txt file in the project folder) and supply your own parameter file (see the material parameters lesson).
  • Contacts: split the top edge at the anode edge with insert-vertex, then assign the left part to the anode and the bottom edge to the cathode. Contact names must match the Electrode section in SDevice.
  • Doping: NDopantActiveConcentration is a generic donor species, fine when you do not need to distinguish Si from Sn. Gaussian profiles or profiles read from SIMS data can also be used.
  • Mesh: the four numbers of define-refinement-size are the maximum cell size in x, y and the minimum in x, y. The Win.Edge window refines the mesh around the anode edge, where the field peaks under reverse bias.
  • SWB parameters: @Ra@ and @Nd@ are replaced by each experiment's values, so one command file produces a whole family of structures.

4. Checking the structure

  1. Open n*_msh.tdr in SVisual; check regions, contacts (colored) and doping.
  2. Inspect the mesh: fine enough at the anode edge and surface? A reasonable node count (thousands to tens of thousands in 2D)?
  3. You can run SDE interactively and draw with the mouse; every action is echoed as a Scheme command in the command window, a great way to learn the syntax.

5. Extensions

  • Field plate: add a dielectric region (e.g. "SiO2") on the surface beyond the anode, and extend the anode metal over it.
  • Guard ring or N-implanted region: add a highly resistive or compensated region around the anode edge.
  • Circular devices: use cylindrical symmetry in SDevice to simulate a round anode with a 2D structure.
