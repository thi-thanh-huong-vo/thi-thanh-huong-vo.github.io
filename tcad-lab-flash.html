Vật liệu nitride, file tham số, lưới phi cục bộ, bẫy với xuyên hầm, khởi tạo, ghi và đọc.Nitride material, parameter files, nonlocal meshes, traps with tunneling, initialization, program and read.

Bài cuối của phần thực hành: một ô nhớ flash bẫy điện tích kiểu SONOS (Si–oxide–nitride–oxide–Si). Đây là bài khó nhất vì kết hợp ba thứ mới: một vật liệu không có sẵn tham số, xuyên hầm phi cục bộ qua oxide, và bẫy trong nitride thay đổi theo thời gian.

1. Cấu trúc và nguyên lý

Thông số trong bài giảng:

  • Đế Si dày 600 nm, loại p, pha tạp hằng 5 × 10¹⁷ cm⁻³ (có thể đổi).
  • Nguồn và máng n⁺: profile Gauss, đỉnh 10²⁰ cm⁻³, sâu 120 nm, giá trị tại độ sâu bằng pha tạp đế, Factor 0,8.
  • Cổng điều khiển poly n⁺ 10²⁰ cm⁻³, dày 5 nm.
  • Oxide 1 (đường hầm) và oxide 2 (chặn): SiO₂, dày 1–5 nm (tham số).
  • Nitride dày 8 nm, khai báo là vật liệu NitrideAsSemiconductor.
  • Bề rộng cổng 100–300 nm (tham số).

Ghi (program): điện áp dương lớn trên cổng làm electron từ kênh xuyên hầm qua oxide 1 và bị bẫy trong nitride. Điện tích âm bị giữ làm VT tăng. Xóa (erase): điện áp âm đẩy electron ra (và/hoặc kéo lỗ trống vào). Đọc (read): đo ID ở VG nhỏ để biết VT cao hay thấp. Với điện tích bẫy \(qN_t\) (cm⁻²) đặt ở tâm lớp nitride:

$$\Delta V_T\approx\frac{qN_t}{C_{\text{eff}}}$$

$$C_{\text{eff}}=\frac{\varepsilon_{ox}}{t_{ox2}+(\varepsilon_{ox}/\varepsilon_N)\,t_N/2}$$

Ví dụ: oxide chặn 5 nm, nitride 8 nm (\(\varepsilon_N\approx 7{,}5\)), \(N_t=5\times10^{12}\) cm⁻² cho \(\Delta V_T\approx 1{,}6\) V.

2. Vật liệu và file tham số

Nitride được khai báo là NitrideAsSemiconductor để SDevice giải phương trình hạt dẫn trong nó; nhờ vậy mới đặt được bẫy và xuyên hầm vào lớp này. Vật liệu này không có tham số sẵn trong cơ sở dữ liệu, nên cần ba việc:

  1. datexcodes.txt: chép file định nghĩa vật liệu vào thư mục dự án và kiểm tra rằng NitrideAsSemiconductor được khai báo là một chất bán dẫn. File trong thư mục dự án được ưu tiên hơn file hệ thống.
  2. Tạo sdevice.par: trong SWB, chuột phải công cụ SDevice → Edit Input → Include Materials, chọn Silicon, SiO2, PolySi và NitrideAsSemiconductor. Vật liệu không có tham số sẵn hiện màu đen và chỉ được tạo khối rỗng.
  3. Viết Nitride.par: tối thiểu gồm hằng số điện môi, độ rộng vùng cấm, ái lực điện tử và khối lượng hiệu dụng. Giá trị Si₃N₄ thường dùng: \(\varepsilon_r\approx 7{,}5\), \(E_g\approx 5\) eV; hãy lấy giá trị từ tài liệu bạn trích dẫn và ghi nguồn.
# sdevice.par -- one block per material, each pulling in its own file
#define ParFileDir .
Material = "Silicon" {
  #includeext "ParFileDir/Silicon.par"
}
Material = "SiO2" {
  #includeext "ParFileDir/SiO2.par"
}
Material = "PolySi" {
  #includeext "ParFileDir/PolySi.par"
}
Material = "NitrideAsSemiconductor" {
  #includeext "ParFileDir/Nitride.par"
}

Thêm khối khối lượng xuyên hầm vào file của oxide và polysilicon, và kiểm tra khối tương ứng trong Silicon.par (mặc định là 0,32 và 0,16):

* add (or edit) in SiO2.par and PolySi.par: tunneling masses for barrier tunneling
BarrierTunneling {
  mt = 0.36, 0.38        * electron, hole tunneling mass [m0] -- values used in the course
}

Khối lượng xuyên hầm là tham số hiệu chỉnh: với electron trong SiO₂, các phép đo Fowler–Nordheim cho giá trị quanh 0,4–0,5 m₀ (Weinberg, 1982). Kết quả ghi/xóa rất nhạy với nó, nên hiệu chỉnh trên một đường đo trước khi dự đoán.

3. Lưới phi cục bộ và xuyên hầm

Math {
  * a nonlocal mesh is a set of 1D lines normal to an interface, along which the
  * tunneling probability is integrated; Length is in cm (9e-7 cm = 9 nm)
  NonLocal "NL_bottom" ( RegionInterface = "R.Ox1/R.Sub"
                         Length = 9e-7  Digits = 4  EnergyResolution = 1e-4 )
  NonLocal "NL_top"    ( RegionInterface = "R.Ox2/R.Gate"
                         Length = 5e-7  Digits = 4  EnergyResolution = 1e-4 )
  Extrapolate  Derivatives  -RelErrControl  Iterations = 30  Method = ParDiSo
}

Mô hình xuyên hầm qua rào (BarrierTunneling) tính xác suất xuyên hầm theo xấp xỉ WKB dọc các đường 1D vuông góc với mặt phân cách. Lưới phi cục bộ "NL_bottom" gắn với mặt phân cách oxide 1/đế, "NL_top" với oxide 2/cổng; Length phải dài hơn bề dày rào (oxide và một phần nitride). Chú ý đơn vị cm trong khối này, khác với µm trong SDE. Hướng dẫn sử dụng mô tả bốn thành phần dòng: electron từ vùng dẫn sang vùng dẫn, lỗ trống từ vùng hóa trị sang vùng hóa trị (luôn được tính), và hai thành phần giữa vùng dẫn và vùng hóa trị (chỉ khi bật xuyên hầm vùng–vùng).

4. Bẫy trong nitride

Physics {
  * tunneling current through the two oxides, electrons and holes
  eBarrierTunneling "NL_bottom"   hBarrierTunneling "NL_bottom"
  eBarrierTunneling "NL_top"      hBarrierTunneling "NL_top"
}
Physics ( Material = "Silicon" ) {
  Mobility ( DopingDependence  HighFieldSaturation )
  Recombination ( SRH ( DopingDependence ) )
}
Physics ( Material = "NitrideAsSemiconductor" ) {
  Traps (
    * deep donor 2.5 eV below EC: neutral when filled, +q when empty
    ( Donor  Level  EnergyMid = 2.5  FromConductionBand  Conc = 1e19
      eXSection = 1e-13  hXSection = 1e-13
      eBarrierTunneling ( NonLocal = "NL_bottom"  NonLocal = "NL_top" )
      hBarrierTunneling ( NonLocal = "NL_bottom"  NonLocal = "NL_top" )
      PooleFrenkel  TrapVolume = 1e-15 )
    * acceptor 1.0 eV below EC: neutral when empty, -q when filled (stores electrons)
    ( Acceptor  Level  EnergyMid = 1.0  FromConductionBand  Conc = 1e19
      eXSection = 1e-13  hXSection = 1e-13
      eBarrierTunneling ( NonLocal = "NL_bottom"  NonLocal = "NL_top" )
      hBarrierTunneling ( NonLocal = "NL_bottom"  NonLocal = "NL_top" )
      PooleFrenkel  TrapVolume = 1e-15 )
  )
}
Plot {
  eDirectTunnel hDirectTunnel  eBarrierTunneling hBarrierTunneling
  eTrappedCharge hTrappedCharge  NonLocal
  ConductionBandEnergy ValenceBandEnergy  ElectricField/Vector  SpaceCharge
}
  • Acceptor: trung hòa khi trống, mang điện −q khi bị chiếm, nên giữ electron khi ghi. Donor: trung hòa khi bị chiếm, +q khi trống.
  • Level: một mức năng lượng duy nhất, đo từ đáy vùng dẫn (FromConductionBand). Conc tính bằng cm⁻³ khi khai báo theo vùng hay vật liệu.
  • eBarrierTunneling(NonLocal=...) trong khai báo bẫy cho phép bẫy trao đổi electron trực tiếp với vùng dẫn của Si và cổng bằng xuyên hầm, đó là cơ chế nạp và xả của ô nhớ.
  • PooleFrenkel: tiết diện bắt tăng theo điện trường do rào Coulomb bị hạ (Frenkel, 1938), quan trọng với dẫn điện trong nitride ở trường lớn.

5. Trình tự giải: khởi tạo, ghi, đọc

Solve {
  * --- initial state: traps empty, then a converged equilibrium ---
  Set ( TrapFilling = Empty )
  Coupled ( Iterations = 100 ) { Poisson }
  Coupled ( Iterations = 100 ) { Poisson Electron }
  Coupled ( Iterations = 100  Digits = 8 ) { Poisson Electron Hole }
  Plot ( FilePrefix = "n@node@_init" )
  UnSet ( TrapFilling )                     * from here on traps evolve with time

  * --- program: gate pulse defined as a piecewise-linear voltage (see text) ---
  NewCurrentPrefix = "prog_"
  Transient ( InitialTime = 0  FinalTime = @t_prog@
              InitialStep = 1e-10  MaxStep = 1e-5  MinStep = 1e-16  Increment = 1.5 )
    { Coupled { Poisson Electron Hole } }
  Plot ( FilePrefix = "n@node@_prog" )

  * --- read: small VD, sweep VG; keep the stored charge fixed while reading ---
  Set ( TrapFilling = Frozen )
  Quasistationary ( Goal { Name = "drain"  Voltage = 0.1 } ) { Coupled { Poisson Electron Hole } }
  NewCurrentPrefix = "read_"
  Quasistationary ( InitialStep = 0.01  MaxStep = 0.05  MinStep = 1e-6
    Goal { Name = "gate"  Voltage = 6 } ) { Coupled { Poisson Electron Hole } }
}

Khởi tạo theo bài giảng: ép bẫy rỗng (TrapFilling = Empty), giải tăng dần từ Poisson tới đủ ba phương trình với độ chính xác cao, lưu trạng thái, rồi bỏ ép để bẫy tự do thay đổi.

Xung ghi. Một cách đặt xung là cho điện áp cổng là hàm tuyến tính từng đoạn theo thời gian ngay trong khối Electrode:

Electrode {
  { Name = "gate"   Voltage = ( 0 at 0,  @V_prog@ at 1e-7,  @V_prog@ at @t_prog@ ) }
  { Name = "source" Voltage = 0 }  { Name = "drain" Voltage = 0 }
  { Name = "substrate" Voltage = 0 }
}

Cách khác là đặt linh kiện trong mạch hỗn hợp với một nguồn xung. Xóa làm tương tự với điện áp âm. Không dùng Quasistationary để ghi: trong chế độ dừng, bẫy luôn ở trạng thái cân bằng nên không mô tả được động học nạp theo thời gian.

Đọc. Khi quét VG để đọc, bẫy không được phép cân bằng lại, nếu không điện tích vừa ghi sẽ biến mất. Đoạn mã dùng TrapFilling = Frozen để giữ nguyên trạng thái chiếm của bẫy; nếu phiên bản của bạn không hỗ trợ, đọc bằng một Transient quét VG rất nhanh (vài micro giây) để lượng nạp xả không đáng kể. VT trước và sau ghi cho cửa sổ nhớ.

6. Điều nên vẽ

  • Giản đồ vùng qua chồng lớp tại giữa kênh, trước và trong xung ghi: thấy oxide 1 bị nghiêng mạnh (xuyên hầm trực tiếp khi oxide mỏng, Fowler–Nordheim khi trường lớn).
  • eTrappedCharge trong nitride theo thời gian: điện tích tập trung gần oxide 1 hay trải đều.
  • VT theo thời gian ghi (thang log) với vài giá trị Vprog và tox1.

7. Bài tập

  1. Với tox1 = 2; 3; 4 nm, tìm thời gian ghi để ΔVT = 2 V ở Vprog = 10 V.
  2. Tính ΔVT từ điện tích bẫy tích phân trong nitride theo công thức ở mục 1 và so với VT đọc được.
  3. Thêm bước xóa và vẽ chu kỳ ghi–đọc–xóa–đọc.
  4. Thay đổi khối lượng xuyên hầm trong SiO₂ ±20 % và cho biết kết quả nhạy đến đâu.
Đáp án và hướng dẫn

Các số dưới đây là tính tay theo mô hình giải tích để bạn có mốc đối chiếu. Kết quả mô phỏng sẽ lệch vài phần trăm đến vài chục phần trăm tùy giá trị \(n_i\), mô hình thu hẹp vùng cấm, lưới và cách trích; khi lệch, hãy giải thích được vì sao.

1. Lượng điện tích cần: với oxide chặn 5 nm và nitride 8 nm, \(C_{eff}\approx 4{,}9\times10^{-7}\) F/cm², nên \(\Delta V_T=2\) V cần \(N_t\approx 6\times10^{12}\) cm⁻² (khoảng 1 µC/cm²). Lưu ý giới hạn: bẫy acceptor 10¹⁹ cm⁻³ trong 8 nm chỉ chứa tối đa 8 × 10¹² cm⁻², tức \(\Delta V_T\) bão hòa ở khoảng 2,6 V; mục tiêu 2 V đã gần trần. Ở VG = 10 V, điện trường trong oxide đường hầm (bỏ qua VFB và thế bề mặt) vào khoảng 9,0; 8,2; 7,6 MV/cm cho tox1 = 2; 3; 4 nm. Theo dòng Fowler–Nordheim \(J=AE^2\exp(-B/E)\) với hằng số Si/SiO₂ điển hình (A ≈ 1,25 × 10⁻⁶ A/V², B ≈ 2,33 × 10⁸ V/cm), mỗi bước giảm 1 MV/cm làm dòng giảm khoảng 30 lần, nên thời gian ghi tăng khoảng một đến hai bậc độ lớn mỗi nm oxide. Chỉ tính FN, thời gian để có 1 µC/cm² vào khoảng 2 ms, 30 ms và 300 ms cho 2; 3; 4 nm. Với 2 nm, xuyên hầm trực tiếp cộng thêm và thường chiếm ưu thế, nên thời gian thực ngắn hơn nhiều (có thể xuống micro giây). Con số chính xác lấy từ mô phỏng: đọc thời điểm ΔVT (hoặc điện tích bẫy tích phân) đạt mục tiêu.

2. Công thức ở mục 1 giả sử điện tích nằm ở tâm nitride. Tổng quát, với điện tích phân bố \(\rho(x)\) và \(x\) đo từ cổng theo bề dày oxide tương đương:

$$\Delta V_T=-\frac{1}{\varepsilon_{ox}}\int x_{eq}\,\rho(x)\,dx$$

Nếu eTrappedCharge dồn về phía oxide 1 (xa cổng), \(\Delta V_T\) thật lớn hơn ước lượng tâm (cỡ 10–30 % với các bề dày ở đây); nếu dồn về phía oxide 2 thì nhỏ hơn. Hai cách tính khớp nhau khi dùng đúng trọng tâm điện tích.

3. Sau xóa, VT giảm về gần giá trị ban đầu hoặc thấp hơn (xóa quá) nếu lỗ trống được bắt vào bẫy donor. Trong SONOS, xóa thường chậm hơn ghi vì electron trong mức sâu 1 eV khó thoát ra, và lỗ trống phải vượt rào oxide cao hơn; nên với cùng |V| và thời gian, VT có thể không về hết, để lại một cửa sổ bị thu hẹp.

4. Xác suất WKB tỉ lệ \(\exp(-\text{const}\sqrt{m}\,\dots)\), nên số mũ B của dòng FN tỉ lệ \(\sqrt{m}\). Ở 9 MV/cm, \(B/E\approx 26\): tăng m 20 % làm số mũ tăng 9,5 % và dòng giảm khoảng 12 lần; giảm m 20 % làm dòng tăng khoảng 15 lần. Tức thời gian ghi đổi khoảng một bậc độ lớn: đây là lý do phải hiệu chỉnh khối lượng xuyên hầm theo phép đo trước khi dùng mô hình để dự đoán.

The last lab: a SONOS-type (Si–oxide–nitride–oxide–Si) charge-trap flash cell. It is the hardest one because it combines three new things: a material with no ready-made parameters, nonlocal tunneling through oxides, and time-dependent traps in the nitride.

1. Structure and principle

Numbers from the lecture:

  • Si substrate 600 nm thick, p-type, constant 5 × 10¹⁷ cm⁻³ (adjustable).
  • n⁺ source and drain: Gaussian, peak 10²⁰ cm⁻³, 120 nm deep, value at depth equal to the substrate doping, Factor 0.8.
  • n⁺ poly control gate, 10²⁰ cm⁻³, 5 nm thick.
  • Oxide 1 (tunnel) and oxide 2 (blocking): SiO₂, 1–5 nm (parameters).
  • 8 nm nitride, declared as the material NitrideAsSemiconductor.
  • Gate width 100–300 nm (parameter).

Program: a large positive gate voltage makes electrons from the channel tunnel through oxide 1 and get trapped in the nitride. The stored negative charge raises VT. Erase: a negative voltage pushes electrons out (and/or pulls holes in). Read: measure ID at a small VG to tell whether VT is high or low. For trapped charge \(qN_t\) (cm⁻²) at the centre of the nitride:

$$\Delta V_T\approx\frac{qN_t}{C_{\text{eff}}}$$

$$C_{\text{eff}}=\frac{\varepsilon_{ox}}{t_{ox2}+(\varepsilon_{ox}/\varepsilon_N)\,t_N/2}$$

Example: a 5 nm blocking oxide, 8 nm nitride (\(\varepsilon_N\approx 7.5\)) and \(N_t=5\times10^{12}\) cm⁻² give \(\Delta V_T\approx 1.6\) V.

2. Materials and parameter files

The nitride is declared as NitrideAsSemiconductor so that SDevice solves the carrier equations in it; only then can traps and tunneling be placed in this layer. The material has no parameters in the database, so three things are needed:

  1. datexcodes.txt: copy the material definition file into the project folder and check that NitrideAsSemiconductor is declared as a semiconductor. A file in the project folder takes precedence over the system file.
  2. Create sdevice.par: in SWB, right-click the SDevice tool → Edit Input → Include Materials, and select Silicon, SiO2, PolySi and NitrideAsSemiconductor. Materials without parameters show in black and get only an empty block.
  3. Write Nitride.par: at least permittivity, band gap, electron affinity and effective masses. Commonly used Si₃N₄ values: \(\varepsilon_r\approx 7.5\), \(E_g\approx 5\) eV; take values from a source you cite and record it.
# sdevice.par -- one block per material, each pulling in its own file
#define ParFileDir .
Material = "Silicon" {
  #includeext "ParFileDir/Silicon.par"
}
Material = "SiO2" {
  #includeext "ParFileDir/SiO2.par"
}
Material = "PolySi" {
  #includeext "ParFileDir/PolySi.par"
}
Material = "NitrideAsSemiconductor" {
  #includeext "ParFileDir/Nitride.par"
}

Add a tunneling-mass block to the oxide and polysilicon files, and check the matching block in Silicon.par (defaults 0.32 and 0.16):

* add (or edit) in SiO2.par and PolySi.par: tunneling masses for barrier tunneling
BarrierTunneling {
  mt = 0.36, 0.38        * electron, hole tunneling mass [m0] -- values used in the course
}

The tunneling mass is a fitting parameter: for electrons in SiO₂, Fowler–Nordheim measurements give about 0.4–0.5 m₀ (Weinberg, 1982). Program/erase results are very sensitive to it, so calibrate on one measured curve before predicting.

3. Nonlocal meshes and tunneling

Math {
  * a nonlocal mesh is a set of 1D lines normal to an interface, along which the
  * tunneling probability is integrated; Length is in cm (9e-7 cm = 9 nm)
  NonLocal "NL_bottom" ( RegionInterface = "R.Ox1/R.Sub"
                         Length = 9e-7  Digits = 4  EnergyResolution = 1e-4 )
  NonLocal "NL_top"    ( RegionInterface = "R.Ox2/R.Gate"
                         Length = 5e-7  Digits = 4  EnergyResolution = 1e-4 )
  Extrapolate  Derivatives  -RelErrControl  Iterations = 30  Method = ParDiSo
}

The barrier tunneling model (BarrierTunneling) computes the tunneling probability in the WKB approximation along 1D lines normal to an interface. The nonlocal mesh "NL_bottom" is attached to the oxide 1/substrate interface and "NL_top" to oxide 2/gate; Length must exceed the barrier thickness (oxide plus part of the nitride). Note the cm units in this block, unlike µm in SDE. The user guide describes four current components: electrons conduction band to conduction band, holes valence band to valence band (always computed), and two between conduction and valence bands (only with band-to-band tunneling on).

4. Traps in the nitride

Physics {
  * tunneling current through the two oxides, electrons and holes
  eBarrierTunneling "NL_bottom"   hBarrierTunneling "NL_bottom"
  eBarrierTunneling "NL_top"      hBarrierTunneling "NL_top"
}
Physics ( Material = "Silicon" ) {
  Mobility ( DopingDependence  HighFieldSaturation )
  Recombination ( SRH ( DopingDependence ) )
}
Physics ( Material = "NitrideAsSemiconductor" ) {
  Traps (
    * deep donor 2.5 eV below EC: neutral when filled, +q when empty
    ( Donor  Level  EnergyMid = 2.5  FromConductionBand  Conc = 1e19
      eXSection = 1e-13  hXSection = 1e-13
      eBarrierTunneling ( NonLocal = "NL_bottom"  NonLocal = "NL_top" )
      hBarrierTunneling ( NonLocal = "NL_bottom"  NonLocal = "NL_top" )
      PooleFrenkel  TrapVolume = 1e-15 )
    * acceptor 1.0 eV below EC: neutral when empty, -q when filled (stores electrons)
    ( Acceptor  Level  EnergyMid = 1.0  FromConductionBand  Conc = 1e19
      eXSection = 1e-13  hXSection = 1e-13
      eBarrierTunneling ( NonLocal = "NL_bottom"  NonLocal = "NL_top" )
      hBarrierTunneling ( NonLocal = "NL_bottom"  NonLocal = "NL_top" )
      PooleFrenkel  TrapVolume = 1e-15 )
  )
}
Plot {
  eDirectTunnel hDirectTunnel  eBarrierTunneling hBarrierTunneling
  eTrappedCharge hTrappedCharge  NonLocal
  ConductionBandEnergy ValenceBandEnergy  ElectricField/Vector  SpaceCharge
}
  • Acceptor: neutral when empty, −q when occupied, so it holds electrons after programming. Donor: neutral when occupied, +q when empty.
  • Level: a single energy level, measured from the conduction band edge (FromConductionBand). Conc is in cm⁻³ for region or material declarations.
  • eBarrierTunneling(NonLocal=...) in the trap declaration lets the traps exchange electrons directly with the conduction band of the Si and the gate by tunneling, which is how the cell charges and discharges.
  • PooleFrenkel: the capture cross-section rises with field because the Coulomb barrier is lowered (Frenkel, 1938), important for conduction in nitride at high field.

5. Solve sequence: initialize, program, read

Solve {
  * --- initial state: traps empty, then a converged equilibrium ---
  Set ( TrapFilling = Empty )
  Coupled ( Iterations = 100 ) { Poisson }
  Coupled ( Iterations = 100 ) { Poisson Electron }
  Coupled ( Iterations = 100  Digits = 8 ) { Poisson Electron Hole }
  Plot ( FilePrefix = "n@node@_init" )
  UnSet ( TrapFilling )                     * from here on traps evolve with time

  * --- program: gate pulse defined as a piecewise-linear voltage (see text) ---
  NewCurrentPrefix = "prog_"
  Transient ( InitialTime = 0  FinalTime = @t_prog@
              InitialStep = 1e-10  MaxStep = 1e-5  MinStep = 1e-16  Increment = 1.5 )
    { Coupled { Poisson Electron Hole } }
  Plot ( FilePrefix = "n@node@_prog" )

  * --- read: small VD, sweep VG; keep the stored charge fixed while reading ---
  Set ( TrapFilling = Frozen )
  Quasistationary ( Goal { Name = "drain"  Voltage = 0.1 } ) { Coupled { Poisson Electron Hole } }
  NewCurrentPrefix = "read_"
  Quasistationary ( InitialStep = 0.01  MaxStep = 0.05  MinStep = 1e-6
    Goal { Name = "gate"  Voltage = 6 } ) { Coupled { Poisson Electron Hole } }
}

Initialization as in the lecture: force the traps empty (TrapFilling = Empty), solve step by step from Poisson to all three equations at high precision, save the state, then release the constraint so the traps evolve freely.

Program pulse. One way to apply the pulse is to give the gate a piecewise-linear voltage in time directly in the Electrode block:

Electrode {
  { Name = "gate"   Voltage = ( 0 at 0,  @V_prog@ at 1e-7,  @V_prog@ at @t_prog@ ) }
  { Name = "source" Voltage = 0 }  { Name = "drain" Voltage = 0 }
  { Name = "substrate" Voltage = 0 }
}

The alternative is to put the device in a mixed-mode circuit with a pulse source. Erase works the same way with a negative voltage. Do not program with Quasistationary: in steady state the traps are always in equilibrium, so the time-dependent charging cannot be described.

Read. While VG is swept to read, the traps must not re-equilibrate, or the stored charge disappears. The code uses TrapFilling = Frozen to keep the trap occupation fixed; if your version does not support it, read with a very fast Transient VG sweep (a few microseconds) so that charging and discharging are negligible. VT before and after programming gives the memory window.

6. What to plot

  • The band diagram through the stack at mid-channel, before and during the program pulse: oxide 1 tilts strongly (direct tunneling for thin oxide, Fowler–Nordheim at high field).
  • eTrappedCharge in the nitride over time: whether the charge sits near oxide 1 or spreads evenly.
  • VT against program time (log scale) for a few values of Vprog and tox1.

7. Exercises

  1. For tox1 = 2, 3, 4 nm, find the program time for ΔVT = 2 V at Vprog = 10 V.
  2. Compute ΔVT from the integrated trapped charge in the nitride with the formula in section 1 and compare with the VT read out.
  3. Add an erase step and plot a program–read–erase–read cycle.
  4. Change the SiO₂ tunneling mass by ±20 % and report how sensitive the results are.
Answers and hints

The numbers below are hand calculations from analytical models, given as reference points. Simulation results will differ by a few to a few tens of percent depending on the \(n_i\) value, band-gap narrowing, mesh and extraction method; when they differ, be able to say why.

1. Charge needed: with a 5 nm blocking oxide and 8 nm nitride, \(C_{eff}\approx 4.9\times10^{-7}\) F/cm², so \(\Delta V_T=2\) V needs \(N_t\approx 6\times10^{12}\) cm⁻² (about 1 µC/cm²). Mind the limit: 10¹⁹ cm⁻³ acceptor traps in 8 nm hold at most 8 × 10¹² cm⁻², so \(\Delta V_T\) saturates near 2.6 V; a 2 V target is already close to the ceiling. At VG = 10 V the tunnel-oxide field (ignoring VFB and surface potential) is about 9.0, 8.2 and 7.6 MV/cm for tox1 = 2, 3, 4 nm. From the Fowler–Nordheim current \(J=AE^2\exp(-B/E)\) with typical Si/SiO₂ constants (A ≈ 1.25 × 10⁻⁶ A/V², B ≈ 2.33 × 10⁸ V/cm), each 1 MV/cm drop cuts the current about 30 times, so program time rises by one to two orders of magnitude per nm of oxide. Counting FN only, the time to pass 1 µC/cm² is about 2 ms, 30 ms and 300 ms for 2, 3 and 4 nm. At 2 nm, direct tunneling adds on top and usually dominates, so the real time is much shorter (possibly microseconds). Take the exact numbers from the simulation: read when ΔVT (or the integrated trapped charge) reaches the target.

2. The formula in section 1 assumes the charge sits at the nitride centre. In general, for a charge distribution \(\rho(x)\) with \(x\) measured from the gate in equivalent oxide thickness:

$$\Delta V_T=-\frac{1}{\varepsilon_{ox}}\int x_{eq}\,\rho(x)\,dx$$

If eTrappedCharge piles up near oxide 1 (far from the gate), the real \(\Delta V_T\) exceeds the centroid estimate (by about 10–30 % for these thicknesses); if it piles up near oxide 2, it is smaller. The two calculations agree once the true charge centroid is used.

3. After erase, VT drops back near its initial value, or below it (over-erase) if holes are captured by the donor traps. In SONOS, erase is usually slower than program because electrons in the deep 1 eV level escape with difficulty and holes face a higher oxide barrier; at the same |V| and time, VT may not fully recover, leaving a narrower window.

4. The WKB probability goes as \(\exp(-\text{const}\sqrt{m}\,\dots)\), so the FN exponent B scales as \(\sqrt{m}\). At 9 MV/cm, \(B/E\approx 26\): raising m by 20 % raises the exponent by 9.5 % and cuts the current about 12 times; lowering m by 20 % raises it about 15 times. So program time shifts by about an order of magnitude, which is why the tunneling mass must be calibrated against measurements before using the model to predict.
