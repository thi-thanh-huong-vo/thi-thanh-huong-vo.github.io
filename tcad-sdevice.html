Mô phỏng điện với Sentaurus DeviceElectrical simulation with Sentaurus Device

Các khối File, Electrode, Physics, Plot, Math, Solve; Quasistationary và đọc kết quả.The File, Electrode, Physics, Plot, Math and Solve sections; Quasistationary and reading results.

Sentaurus Device (SDevice) đọc cấu trúc và lưới từ SDE, giải các phương trình bán dẫn và ghi ra dòng, áp và phân bố bên trong linh kiện. File lệnh gồm vài khối cố định; hiểu từng khối là đủ để chạy hầu hết mô phỏng điện.

1. File lệnh cho đặc tuyến thuận

File {
  Grid      = "n@node|sde@_msh.tdr"   * structure and mesh from SDE
  Parameter = "Ga2O3.par"             * material parameters
  Current   = "n@node@_des.plt"       * electrical results
  Plot      = "n@node@_des.tdr"       * internal distributions
  Output    = "n@node@_des.log"       * run log
}

Electrode {
  { Name = "anode"   Voltage = 0.0  Schottky  Barrier = @PhiB@ }
  { Name = "cathode" Voltage = 0.0 }
}

Physics {
  Temperature = @T@
  Fermi
  Mobility ( DopingDependence  HighFieldSaturation )
  Recombination ( SRH )
}

Plot {
  eDensity  ElectricField/Vector  Potential  SpaceCharge
  eCurrent/Vector  ConductionBandEnergy  eQuasiFermiEnergy
  DopingConcentration
}

Math {
  Extrapolate
  Derivatives
  RelErrControl
  Digits = 5
  Iterations = 20
  NotDamped = 50
  ExtendedPrecision      * helps with the tiny n_i of ultra-wide bandgap materials
  ExitOnFailure
}

Solve {
  * 1. Equilibrium: Poisson only, then add electrons
  Coupled ( Iterations = 100 ) { Poisson }
  Coupled { Poisson Electron }

  * 2. Forward sweep of the anode from 0 to 2 V
  Quasistationary (
    InitialStep = 1e-3  MinStep = 1e-6  MaxStep = 0.05
    Goal { Name = "anode" Voltage = 2.0 }
  ) { Coupled { Poisson Electron } }
}

2. Ý nghĩa từng khối

KhốiNhiệm vụ
FileTên các file vào/ra. @node|sde@ lấy đúng cấu trúc của thí nghiệm hiện tại.
ElectrodeTên điện cực (khớp với SDE), điện áp ban đầu, loại tiếp xúc. Schottky Barrier = 1.2 đặt chiều cao rào 1,2 eV; không ghi gì là tiếp xúc ohmic.
PhysicsCác mô hình vật lý: nhiệt độ, thống kê Fermi–Dirac, độ linh động phụ thuộc pha tạp và bão hòa vận tốc, tái hợp SRH. Có thể viết riêng cho từng vùng, vật liệu, mặt phân cách hay điện cực.
PlotCác đại lượng được lưu vào file .tdr để xem phân bố.
MathTùy chọn số: số lần lặp Newton, độ chính xác, ngoại suy giữa các bước, dừng khi lỗi.
SolveTrình tự giải: điểm cân bằng trước, rồi quét điện áp.

3. Quét điện áp: Quasistationary

Quasistationary tăng một biến "thời gian" ảo \(t\) từ 0 đến 1, và điện áp điện cực đi tuyến tính từ giá trị ban đầu tới Goal. Bước bắt đầu bằng InitialStep; nếu hội tụ tốt, bước được nhân lên (tới MaxStep); nếu không hội tụ, bước bị chia nhỏ (tới MinStep, quá nữa thì mô phỏng dừng). Với MaxStep = 0.05 và quét 0–2 V, khoảng cách điểm lớn nhất là 0,1 V.

4. Phương trình nào cần giải

Ga₂O₃ chỉ có electron dẫn điện; nồng độ lỗ trống nhỏ đến mức gần như bằng 0. Giải thêm phương trình lỗ trống (Hole) không thêm thông tin cho đặc tuyến thuận nhưng làm mô phỏng dễ mất ổn định. Chỉ thêm Hole khi cần ion hóa va chạm, chiếu sáng UV hay tiếp giáp với vật liệu loại p như NiO.

5. Đọc kết quả

  • n*_des.plt: các cột như anode OuterVoltage, anode TotalCurrent. Dòng tính theo A/µm (2D, trên một µm chiều sâu); chia cho chiều rộng anode để có mật độ dòng, hoặc dùng hệ số diện tích trong khối Physics hay đối xứng trụ.
  • n*_des.tdr: phân bố điện trường, nồng độ electron, giản đồ vùng tại điểm cuối của mỗi lần giải (có thể yêu cầu lưu ở nhiều điểm bằng lệnh Plot trong Solve).

6. Bổ sung cho tiếp xúc Schottky

  • Hạ rào do lực ảnh: bật mô hình hạ rào cho điện cực anode trong một khối Physics (Electrode = "anode") { ... }; quan trọng khi mô phỏng dòng rò ngược.
  • Xuyên hầm qua rào: dùng mô hình xuyên hầm phi cục bộ (khai báo lưới phi cục bộ trong Math và bật xuyên hầm cho anode). Cần khi pha tạp cao hoặc điện trường lớn, nơi phát xạ nhiệt điện tử–trường chiếm ưu thế.

Tên chính xác của các từ khóa này phụ thuộc phiên bản; tra mục "Schottky contacts" và "Tunneling" trong Sentaurus Device User Guide.

Sentaurus Device (SDevice) reads the structure and mesh from SDE, solves the semiconductor equations, and writes out currents, voltages and internal distributions. The command file has a few fixed sections; understanding each is enough for most electrical simulations.

1. A command file for the forward characteristic

File {
  Grid      = "n@node|sde@_msh.tdr"   * structure and mesh from SDE
  Parameter = "Ga2O3.par"             * material parameters
  Current   = "n@node@_des.plt"       * electrical results
  Plot      = "n@node@_des.tdr"       * internal distributions
  Output    = "n@node@_des.log"       * run log
}

Electrode {
  { Name = "anode"   Voltage = 0.0  Schottky  Barrier = @PhiB@ }
  { Name = "cathode" Voltage = 0.0 }
}

Physics {
  Temperature = @T@
  Fermi
  Mobility ( DopingDependence  HighFieldSaturation )
  Recombination ( SRH )
}

Plot {
  eDensity  ElectricField/Vector  Potential  SpaceCharge
  eCurrent/Vector  ConductionBandEnergy  eQuasiFermiEnergy
  DopingConcentration
}

Math {
  Extrapolate
  Derivatives
  RelErrControl
  Digits = 5
  Iterations = 20
  NotDamped = 50
  ExtendedPrecision      * helps with the tiny n_i of ultra-wide bandgap materials
  ExitOnFailure
}

Solve {
  * 1. Equilibrium: Poisson only, then add electrons
  Coupled ( Iterations = 100 ) { Poisson }
  Coupled { Poisson Electron }

  * 2. Forward sweep of the anode from 0 to 2 V
  Quasistationary (
    InitialStep = 1e-3  MinStep = 1e-6  MaxStep = 0.05
    Goal { Name = "anode" Voltage = 2.0 }
  ) { Coupled { Poisson Electron } }
}

2. What each section does

SectionPurpose
FileInput/output file names. @node|sde@ picks the structure of the current experiment.
ElectrodeElectrode names (matching SDE), initial voltages, contact type. Schottky Barrier = 1.2 sets a 1.2 eV barrier; no keyword means ohmic.
PhysicsPhysical models: temperature, Fermi–Dirac statistics, doping-dependent mobility with velocity saturation, SRH recombination. Can be written per region, material, interface or electrode.
PlotQuantities saved to the .tdr file to view distributions.
MathNumerical options: Newton iterations, precision, extrapolation between steps, stop on failure.
SolveThe solution sequence: equilibrium first, then the voltage sweep.

3. Sweeping voltage: Quasistationary

Quasistationary ramps a virtual "time" \(t\) from 0 to 1, and the electrode voltage moves linearly from its initial value to the Goal. The step starts at InitialStep; if convergence is good the step grows (up to MaxStep); if not, it shrinks (down to MinStep, beyond which the simulation stops). With MaxStep = 0.05 over a 0–2 V sweep, the largest point spacing is 0.1 V.

4. Which equations to solve

In Ga₂O₃ only electrons conduct; the hole density is practically zero. Adding the hole equation (Hole) adds nothing to the forward characteristic but makes the simulation less stable. Add Hole only for impact ionization, UV illumination, or junctions with p-type materials such as NiO.

5. Reading the results

  • n*_des.plt: columns such as anode OuterVoltage and anode TotalCurrent. Current is in A/µm (2D, per µm of depth); divide by the anode width for current density, or use an area factor in Physics or cylindrical symmetry.
  • n*_des.tdr: field, electron density and band diagrams at the end of each solve (more snapshots can be requested with Plot commands inside Solve).

6. Additions for Schottky contacts

  • Image-force barrier lowering: enable barrier lowering for the anode in a Physics (Electrode = "anode") { ... } block; important when simulating reverse leakage.
  • Tunneling through the barrier: use the nonlocal tunneling model (declare a nonlocal mesh in Math and enable tunneling at the anode). Needed at high doping or high fields, where thermionic-field emission dominates.

The exact keywords depend on the version; look up "Schottky contacts" and "Tunneling" in the Sentaurus Device User Guide.
