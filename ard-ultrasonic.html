Cảm biến siêu âm HC-SR04The HC-SR04 ultrasonic sensor

Sóng âm, hiệu ứng áp điện, đo thời gian bay, hệ số 58, bù nhiệt độ và ứng dụng.Sound waves, the piezoelectric effect, time of flight, the factor 58, temperature correction and applications.

Cảm biến siêu âm HC-SR04 là "đôi mắt" của cả hai dự án trong môn học. Bài này đi từ vật lý (sóng âm, hiệu ứng áp điện) đến cách đo khoảng cách bằng thời gian bay của tiếng vọng và code để dùng ngay.

1. Sóng âm và siêu âm

Sóng là một nhiễu động truyền năng lượng từ điểm này sang điểm khác trong môi trường; các phần tử của môi trường chỉ dao động tại chỗ chứ không đi theo sóng. Sóng âm là sóng dọc: phần tử dao động cùng phương truyền, môi trường bị nén và giãn liên tiếp. (Sóng ngang thì dao động vuông góc với phương truyền; sóng mặt nước và sóng Rayleigh trên bề mặt chất rắn là tổ hợp của cả hai.) Tốc độ âm phụ thuộc vào môi trường, qua mô-đun khối và mật độ; trong không khí:

$$c\approx 331{,}3+0{,}606\,T\ \ \text{m/s}\quad(T\ \text{tính bằng}\ ^\circ\text{C})$$

tức khoảng 343 m/s ở 20 °C. Âm thanh con người nghe được nằm trong khoảng 20 Hz–20 kHz; trên 20 kHz là siêu âm, dùng để đo khoảng cách, chụp ảnh y tế, kiểm tra không phá hủy, làm sạch.

2. Hiệu ứng áp điện: cách tạo và thu siêu âm

Vật liệu áp điện (như gốm PZT) sinh điện áp khi bị biến dạng cơ học, và ngược lại biến dạng khi được đặt điện áp. Một biến tử dạng unimorph gồm một đĩa gốm áp điện dán trên tấm kim loại: điện áp xoay chiều làm đĩa uốn lên xuống, một chiếc nón nhỏ gắn ở tâm giúp phát sóng ra không khí hiệu quả. Hiệu ứng này thuận nghịch, nên cùng loại biến tử cũng thu được sóng vọng và biến nó thành điện áp. Biến tử hoạt động tốt nhất ở tần số cộng hưởng; HC-SR04 dùng 40 kHz.

Thời gian \(t\) là quãng đường đi và về, nên khoảng cách là \(d=c\,t/2\). Với c = 340 m/s và t tính bằng µs:

$$d\,[\text{cm}]=\frac{340\times10^{2}\times t\times10^{-6}}{2}=\frac{t}{58{,}8}$$

Datasheet viết \(t/58\); bài giảng dùng \(t/58{,}2\), ứng với c ≈ 343,6 m/s, tức không khí khoảng 21 °C.

4. Code

Bản dưới viết lại từ bài giảng, thêm một thời gian chờ 30 ms cho pulseIn(): nếu không có vật trong tầm, hàm trả về 0 thay vì treo chương trình tới 1 giây (giá trị chờ mặc định).

Ultrasonic.inoChạy thử trên Wokwi ↗
// Ultrasonic.ino -- HC-SR04 distance meter
// HC-SR04: VCC -> 5 V, GND -> GND, Trig -> pin 11, Echo -> pin 10
const int TRIG = 11;
const int ECHO = 10;

// Send a 10 us trigger pulse and convert the echo time to centimetres.
// Returns -1 when no echo arrives within 30 ms (nothing in range).
float readCm() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  unsigned long t = pulseIn(ECHO, HIGH, 30000UL);   // echo pulse width [us]
  if (t == 0) return -1.0;
  return t / 58.2;                                  // round trip at ~343 m/s
}

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
}

void loop() {
  float d = readCm();
  if (d < 0) {
    Serial.println("out of range");
  } else {
    Serial.print(d, 1);
    Serial.println(" cm");
  }
  delay(100);                      // keep the cycle longer than 60 ms (datasheet)
}

Nguồn: Viết lại từ bài giảng (thêm thời gian chờ cho pulseIn), dùng tự do

Kết hợp với LED: sáng khi có vật gần hơn 20 cm. Chú ý dòng pinMode(LED, OUTPUT); bản trong slide thiếu dòng này, khi đó digitalWrite(LED, HIGH) chỉ bật điện trở kéo lên bên trong và LED sáng rất mờ.

UltrasonicLed.inoChạy thử trên Wokwi ↗
// UltrasonicLed.ino -- light an LED when an object is closer than 20 cm
const int TRIG = 11;
const int ECHO = 10;
const int LED  = 9;                // LED + 220 ohm to GND
const float WARN_CM = 20.0;

// Send a 10 us trigger pulse and convert the echo time to centimetres.
// Returns -1 when no echo arrives within 30 ms (nothing in range).
float readCm() {
  digitalWrite(TRIG, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG, LOW);
  unsigned long t = pulseIn(ECHO, HIGH, 30000UL);   // echo pulse width [us]
  if (t == 0) return -1.0;
  return t / 58.2;                                  // round trip at ~343 m/s
}

void setup() {
  Serial.begin(9600);
  pinMode(TRIG, OUTPUT);
  pinMode(ECHO, INPUT);
  pinMode(LED, OUTPUT);            // without this line the LED only glows dimly
}

void loop() {
  float d = readCm();
  Serial.println(d);
  if (d > 0 && d < WARN_CM) {
    digitalWrite(LED, HIGH);
  } else {
    digitalWrite(LED, LOW);
  }
  delay(100);
}

5. Ứng dụng và giới hạn

Cảm biến siêu âm dùng trong công nghiệp để đếm vật trên băng tải, kiểm soát độ võng của cuộn giấy hay màng mỏng, phát hiện tấm kính (vật trong suốt mà cảm biến quang khó thấy), đo mực chất lỏng. Ưu điểm là không phụ thuộc màu sắc hay độ trong suốt. Hạn chế: vật mềm hấp thụ âm (vải, bọt), bề mặt nghiêng phản xạ sóng đi chỗ khác, vật quá nhỏ hay quá gần (dưới 2 cm) không đo được, và hai cảm biến cùng tần số đặt gần nhau có thể nhiễu lẫn nhau.

6. Bài tập

  1. Echo đo được 1750 µs. Tính khoảng cách theo công thức của datasheet và theo bài giảng.
  2. Robot chạy ngoài trời ở 35 °C nhưng code vẫn dùng 58,2. Sai số ở 1 m là bao nhiêu?
  3. Vì sao không nên đo liên tục với chu kỳ 10 ms?
  4. Sửa hàm readCm() để bù nhiệt độ theo một biến tempC.
Đáp án và hướng dẫn

1. 1750/58 = 30,2 cm; 1750/58,2 = 30,1 cm.

2. Ở 35 °C, c = 331,3 + 0,606 × 35 = 352,5 m/s, tức thực tế 1 cm ứng với 2/0,03525 = 56,7 µs. Vật ở 1 m cho t = 5674 µs; code tính 5674/58,2 = 97,5 cm, đọc thiếu khoảng 2,5 cm (2,5 %).

3. Ở tầm 4 m, sóng đi về mất khoảng 23 ms, cộng thêm tiếng vọng nhiều lần từ tường. Nếu kích lần đo mới trước khi tiếng vọng cũ tắt hẳn, cảm biến có thể nhận nhầm tiếng vọng của lần trước và báo khoảng cách sai. Datasheet khuyến nghị chu kỳ trên 60 ms.

4. Thay dòng cuối của readCm():

float c = 331.3 + 0.606 * tempC;     // m/s
return t * c / 20000.0;               // t [us] * c [m/s] * 100 / 2 / 1e6 = cm

Có thể đọc tempC từ TMP36 của bài trước.

The HC-SR04 ultrasonic sensor is the "eyes" of both course projects. This lesson goes from the physics (sound waves, the piezoelectric effect) to measuring distance from the time of flight of an echo, with code to use right away.

1. Sound and ultrasound

A wave is a disturbance that carries energy from point to point through a medium; the particles of the medium only oscillate in place and do not travel with the wave. Sound is a longitudinal wave: particles oscillate along the direction of travel, and the medium is compressed and expanded in turn. (In a transverse wave the oscillation is perpendicular to the direction of travel; water waves and Rayleigh waves on a solid surface combine both.) The speed of sound depends on the medium through its bulk modulus and density; in air:

$$c\approx 331.3+0.606\,T\ \ \text{m/s}\quad(T\ \text{in}\ ^\circ\text{C})$$

about 343 m/s at 20 °C. Human hearing covers about 20 Hz–20 kHz; above 20 kHz is ultrasound, used for ranging, medical imaging, non-destructive testing and cleaning.

2. The piezoelectric effect: making and hearing ultrasound

A piezoelectric material (such as PZT ceramic) produces a voltage when mechanically strained and, conversely, strains when a voltage is applied. A unimorph transducer is a piezoelectric ceramic disc bonded to a metal plate: an AC voltage makes the disc flex up and down, and a small cone at its centre couples the sound efficiently into air. The effect is reversible, so the same kind of transducer also picks up the echo and turns it back into a voltage. A transducer works best at its resonance frequency; the HC-SR04 uses 40 kHz.

3. How the HC-SR04 measures distance

Parameter (datasheet)Value

Recommended cycleover 60 ms

The time \(t\) covers the trip out and back, so the distance is \(d=c\,t/2\). With c = 340 m/s and t in µs:

$$d\,[\text{cm}]=\frac{340\times10^{2}\times t\times10^{-6}}{2}=\frac{t}{58.8}$$

The datasheet writes \(t/58\); the lecture uses \(t/58.2\), which corresponds to c ≈ 343.6 m/s, air at about 21 °C.

4. Code

The version below is rewritten from the lecture and adds a 30 ms timeout to pulseIn(): if nothing is in range the function returns 0 instead of stalling the program for up to one second (the default timeout).

5. Applications and limits

Industry uses ultrasonic sensors to count objects on conveyor belts, control the sag of paper and foil rolls, detect glass panes (transparent objects that optical sensors struggle with) and monitor liquid levels. Their advantage is independence from colour and transparency. Limits: soft objects absorb sound (cloth, foam), slanted surfaces reflect the wave elsewhere, very small or very close objects (under 2 cm) cannot be measured, and two sensors on the same frequency close together can interfere.

6. Exercises

  1. The echo lasts 1750 µs. Compute the distance with the datasheet formula and with the lecture's.
  2. A robot runs outdoors at 35 °C but the code still uses 58.2. What is the error at 1 m?
  3. Why not measure continuously every 10 ms?
  4. Modify readCm() to compensate for temperature using a variable tempC.
Answers and hints

1. 1750/58 = 30.2 cm; 1750/58.2 = 30.1 cm.

2. At 35 °C, c = 331.3 + 0.606 × 35 = 352.5 m/s, so 1 cm really takes 2/0.03525 = 56.7 µs. An object at 1 m gives t = 5674 µs; the code computes 5674/58.2 = 97.5 cm, reading about 2.5 cm (2.5 %) short.

3. At 4 m range the round trip takes about 23 ms, plus multiple echoes off walls. Triggering a new measurement before old echoes have died away lets the sensor pick up the previous echo and report a wrong distance. The datasheet recommends a cycle over 60 ms.

4. Replace the last line of readCm():

float c = 331.3 + 0.606 * tempC;     // m/s
return t * c / 20000.0;               // t [us] * c [m/s] * 100 / 2 / 1e6 = cm

tempC can come from the TMP36 of the previous lesson.
